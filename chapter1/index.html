少量符号，先翻译成动作

本章默认你认识普通函数、求导和积分。下面把例题额外用到的计数、级数与“概率 1”解释清楚；不需要一开始就背。

阶乘、组合数、二项式：是在数什么？

阶乘：\(n!=n(n-1)\cdots1\)，表示 n 个不同物品排队的方式数，约定 0!=1。例如 3 人排队有 3×2×1=6 种。

组合数：从 n 个对象里选 k 个，只看选中谁、不计内部顺序：

\[\binom nk=\frac{n!}{k!(n-k)!},\qquad0\le k\le n.\]

先把 n 个对象排队，再让前 k 个入选，每一组人会因前后内部排法重复 k!(n−k)! 次，所以要除掉。\(\binom nk\) 有时也写成 \(C_n^k\)。

二项式展开：\((a+b)^n=\sum_{k=0}^n\binom nk a^kb^{n-k}\)。因为 n 个括号中选 k 个取 a，另外 n−k 个取 b，正好有 \(\binom nk\) 种选法。例 1.2 与常见分布会用到它。

三个反复使用的级数与求和公式\[\sum_{k=0}^{\infty}z^k=\frac1{1-z}\quad(|z|<1),\qquad e^z=\sum_{k=0}^{\infty}\frac{z^k}{k!}.\]

第一条来自有限和 \(1+z+\cdots+z^n=(1-z^{n+1})/(1-z)\)，当 |z|<1 时尾项趋 0。第二条是指数函数的幂级数，实数和复数 z 都成立；取 z=−1 得到 \(e^{-1}=1-1+1/2!-1/3!+\cdots\)。

\[\sum_{k=1}^nk=\frac{n(n+1)}2,\qquad\sum_{k=1}^nk^2=\frac{n(n+1)(2n+1)}6.\]

第一条把首尾配对即可得到；第二条可把 \((k+1)^3-k^3=3k^2+3k+1\) 从 k=0 加到 n，让左边逐项抵消，再代入第一条解出平方和。例 1.10 用它计算加权方差。

“几乎处处/几乎必然”就是“除了一个概率为 0 的例外集合”。若 U 在 (0,1) 均匀抽取，每个指定点的概率都为 0，但总会抽到某个点。概率为 0 不等于集合为空；概率为 1 的性质也允许在个别零概率结果上不成立。后面的条件期望与收敛都按这个含义理解。
01 / 概率论先说清楚的三个对象

概率空间：有哪些结果，哪些问题能问，各有多大概率

从“抛两次硬币，至少一次正面的概率是多少”出发：要算这个数，先得说清哪些完整结果算成功，再给它们分配概率。概率空间就是把这两步写成一套一致的规则。下面的事件域与公理，都是为避免漏算、重算或问出模型不能回答的问题。

先不看公式。抛两次硬币，一次完整记录可能是“先正后反”。我们先列出所有记录，再规定什么算一个事件，最后给事件分配概率。这三件事合起来叫概率空间。

第一件：把“一个结果”和“所有结果”分开

用 H 表示正面、T 表示反面。HH 表示两次都是正面，HT 表示先正后反。全部可能记录组成一个集合，叫样本空间，记作大写希腊字母 Ω：

样本空间：把全部可能结果列在大括号里

\[\Omega=\{HH,HT,TH,TT\}.\]

小写 ω 表示其中一个完整结果，比如 ω=HT。写“ω∈Ω”读作“ω 属于 Ω”，意思只是这张记录在结果清单里。Ω 是整张清单，ω 是清单中的一项，不是同一个对象。

第二件：“事件”是满足某句话的那些结果

事件“至少一次正面”不是一条单独记录，因为 HH、HT、TH 都能使它发生。把这三条记录放进集合 A，就得到这个事件的数学表达：

\[A=\{HH,HT,TH\}.\]

事件 A 发生，意思是实际抽到的 ω 在 A 里面。A 是 Ω 的一个子集，写成 A⊆Ω。“两次都不是正面”是相反事件，记作 Aᶜ，这里 Aᶜ={TT}。

记号读成一句话对两次硬币的具体含义
A∪BA 或 B 至少发生一个把两份结果清单合在一起，重复的只留一次
A∩BA 与 B 同时发生只保留两张清单里共同的记录
AᶜA 不发生从 Ω 中删去 A 的记录
∅空集没有任何记录满足这个条件，即不可能事件

第三件：事件域 ℱ 与概率 P，各管什么？

事件域 ℱ（花体 F）是一份“允许按本模型询问概率的事件清单”。它的成员是事件，也就是一个个集合，不是数值。在这个有限硬币例子里，可以把 Ω 的所有子集都列入 ℱ。

概率 P是一条赋值规则：输入一个允许的事件 A，输出一个 0 到 1 的数 P(A)。它回答“这个事件的可能性占多少”。公平、独立地抛两次时，四条完整记录各占 1/4，所以 P(A)=3/4。

定义名称：概率空间（三个对象组成的一套模型）

\[(\Omega,\mathcal F,P).\]

这不是要算一个乘积。圆括号只表示把“全部结果 Ω、允许的事件 ℱ、概率规则 P”放在一起。后面的随机变量定义会用这三个对象，所以不能跳过它们。

事件域为什么又叫 σ 域？

我们要求这份事件清单在做常见的逻辑操作后仍然完整。符合以下三条的清单叫σ 域，在概率问题里也叫事件域：

  1. Ω 本身要在清单里：可以问“某个可能结果发生了”这个必然事件。
  2. 若 A 在清单里，Aᶜ 也要在：既能问“A 发生”，也能问“A 不发生”。
  3. 若 A₁、A₂、……都在清单里，“它们至少有一个发生”的事件也要在。

σ 域三条要求的符号写法

\[\Omega\in\mathcal F;\qquad A\in\mathcal F\Rightarrow A^c\in\mathcal F;\qquad A_1,A_2,\ldots\in\mathcal F\Rightarrow\bigcup_{n=1}^{\infty}A_n\in\mathcal F.\]

这里“∈”表示在清单里；“⇒”表示前一句能推出后一句；大写 ∪ 表示把 n=1、2、3……这些事件取“或”。能按整数编号的无限多个叫“可数多个”。在连续问题中，保留这个限制能使概率规则保持一致；本章有限的枚举例子里，所有子集都允许时，三条自然满足。

概率三公理：怎样分配才不会自相矛盾？

概率公理是模型必须服从的基本规则，不是从其他公式算出来的结论。第一，概率不能为负；第二，全部可能结果的总概率是 1；第三，互不重叠的事件可以直接相加。

\[P(A)\ge0,\qquad P(\Omega)=1,\qquad P\!\left(\bigcup_{n=1}^{\infty}A_n\right)=\sum_{n=1}^{\infty}P(A_n)\quad\text{当各 }A_n\text{ 互不重叠时}.\]

Σ 是求和号，把后面所有项加起来。互不重叠是 Aᵢ∩Aⱼ=∅（i≠j）：同一条结果不会被加两次。A 和 Aᶜ 正好把 Ω 分成两块，所以 P(A)+P(Aᶜ)=1，移项得到 P(Aᶜ)=1−P(A)。两个一般事件可能重叠，先加会多算交集一次，所以要减去一次：

结论名称：两事件的加法公式

\[P(A\cup B)=P(A)+P(B)-P(A\cap B).\]

互斥与独立：一个是不能同时发生，一个是不改变概率

互斥定义为 A∩B=∅。独立定义为 P(A∩B)=P(A)P(B)，也就是知道 B 发生后，不改变 A 的概率。两个本来都有正概率的互斥事件不独立：一个发生，另一个立刻变得不可能。

概率能怎样取极限？后面的 CDF 与收敛会用到

若事件 Aₙ 一层层缩小，则它们最终共同留下的是交集，概率也趋向交集概率；若一层层扩大，则最终收进来的是并集，概率趋向并集概率：

\[A_1\supseteq A_2\supseteq\cdots\Rightarrow P(A_n)\to P(\bigcap_nA_n),\qquad A_1\subseteq A_2\subseteq\cdots\Rightarrow P(A_n)\to P(\bigcup_nA_n).\]

这是概率连续性，不是额外假设：扩大时，每次新增的部分互不重叠，按可数可加性加起来即可；缩小则对补集用同一结论。

条件概率、全概率、贝叶斯：先认识名字，再看推导

条件概率回答：“已经知道 B 发生，只在 B 的范围里看，A 占多少？”竖线“|”读作“在……条件下”。只要 P(B)>0，就定义：

\[P(A\mid B)=\frac{P(A\cap B)}{P(B)}.\]

分子是 A、B 都满足的那块，分母是现在允许考虑的全部范围 B。将分母乘回去，就得到乘法公式 P(A∩B)=P(B)P(A|B)。

全概率公式回答：“A 可以来自几种互斥来源，把每个来源的贡献加起来是多少？”设 Bⱼ 是这些来源，彼此互斥且合起来是 Ω。事件 A 被切成 A∩Bⱼ，于是：

\[P(A)=\sum_jP(A\cap B_j)=\sum_jP(B_j)P(A\mid B_j).\]

贝叶斯公式反过来问：“既然 A 发生，它来自来源 Bⱼ 的概率是多少？”把条件概率定义与刚算出的 P(A) 合起来：

\[P(B_j\mid A)=\frac{P(B_j\cap A)}{P(A)}=\frac{P(B_j)P(A\mid B_j)}{\sum_kP(B_k)P(A\mid B_k)}.\]

例：等概率选甲乙盒，再取一根螺栓。甲盒长螺栓比例 3/5、乙盒 2/3。令 A=“取到长的”，B₁=“选甲”。来自甲且是长的占 (1/2)(3/5)=3/10；来自乙且是长的占 (1/2)(2/3)=1/3；二者相加 P(A)=19/30。已经知道是长的，再问来自甲，就在这 19/30 里面取甲的 3/10，得到 9/19。

本节先记清对象：ω 是一条结果，Ω 是所有结果，事件 A 是一批结果，ℱ 是允许的事件清单，P 是给事件赋概率的规则。
02 / 学习指导 1.1 · 第 2 点

随机变量与分布：给结果打分，再描述分数

列出完整结果后，我们往往不关心记录本身，而关心人数、等待时间、收入这些数。于是先用随机变量把记录变成数，再用分布汇总每个数出现的概率。两者各做一步：X 规定怎样读数，F 规定这些读数怎样分配概率。

随机变量不是一个“会自己乱变的字母”，而是一条固定的计分规则：完整结果进来，一个数出去。

仍抛两次硬币，令 X 为正面次数：\(X(HH)=2\)，\(X(HT)=X(TH)=1\)，\(X(TT)=0\)。随机的是抽到哪张结果卡，计分规则 X 本身是固定的。

随机变量的定义：一条结果怎样变成一个数？

先给正式定义的文字版本：在已经规定好的概率空间 (Ω,ℱ,P) 上，如果一条规则 X 给每个结果 ω 分配一个实数，并且对任意实数门槛 x，“X 的得分不超过 x”的那些结果组成一个允许的事件，就称 X 为一个随机变量。后半条要求叫作X 对事件域 ℱ 可测。

“可测”就是这个要求的名称：筛出事件之后，原来的概率 P 必须能处理它。这里也不是物理上的“拿仪器去测量”。

随机变量定义的符号写法（这两行合起来才是完整条件）

\[X:\Omega\longrightarrow\mathbb R,\qquad\omega\longmapsto X(\omega).\] \[\text{对每个实数 }x,\qquad A_x:=\{\omega\in\Omega:X(\omega)\le x\}\in\mathcal F.\]

第一行读作“X 是把结果集合 Ω 中的记录，送到实数集合 ℝ 的一个函数”；长箭头就是输入到输出。第二行先用 Aₓ 给筛出来的集合起个短名；“:=”读作“定义为”。然后要求 Aₓ 是允许的事件。这是定义/合法性要求，不是一道等着你算出数值的等式。

当 ℱ 包含这个有限 Ω 的全部子集时，不管怎么设门槛，筛出的结果都在清单中，因此这条计分规则确实是随机变量。满足“可测”之后，我们才可以放心地写 P(X≤x)，把这些筛选问题交给 P 求概率。

为什么定义不能只说“给每条记录一个数”？一个小反例

设模型只保留“第一枚是正面还是反面”的信息，允许的事件清单是 ℱ={∅,Ω,{HH,HT},{TH,TT}}。这四个集合满足 σ 域要求，但没有列出每个单独结果。

“第一枚正面记 1，否则记 0”是可测的，因为任何门槛筛出来的集合都在这四项里。但“总正面数”这条规则在 x=0.5 时筛出 {TT}，它不在这份 ℱ 中。我们原来的 P 没有给这个更细的事件赋概率，所以它不是这个概率空间上的随机变量。若把事件清单扩展到所有子集，它又可以成为随机变量。

这说明“可测”是在检查数值规则与当前事件/信息系统是否匹配。对本章通常使用的完整有限模型，验证很简单；你不需要先研究更复杂的测度论。

分布函数的定义：每个门槛左边累计了多少概率？

现在固定随机变量 X。我们让数值门槛 x 左右移动，每个位置都去算事件“X≤x”的概率。把这个概率作为 x 的一个函数，就叫 X 的分布函数，英文简称 CDF，记作 Fₓ(x)。下标 X 说明在研究哪个随机变量；括号里的小写 x 是可以改变的门槛。

定义公式：把“X 不超过门槛 x 的概率”命名为 Fₓ(x)

\[F_X(x)=P(X\le x).\]

它是描述分布的通用方式，离散、连续或两者混合都能用。它的几条性质不是额外背诵的规定，而是由刚才的概率定义推出：门槛向右移，只会收进更多结果，所以 F 不减；移到越来越左边时概率趋 0，移到越来越右边则趋 1；从右侧逼近 x 时，筛出的事件缩到 {X≤x}，由概率连续性得到 F 右连续。

还可以从 CDF 算区间概率。对 a<b，“X≤b”的结果分成互斥两部分：“X≤a”与“a<X≤b”。因此 F(b)=F(a)+P(a<X≤b)，移项得到下面第一式。第二式则把 x 左边已累计的概率扣掉，只留下恰好落在 x 上的那一份：

由定义推得的两条取概率公式（不是新的分布假设）

\[P(a<X\le b)=F_X(b)-F_X(a),\qquad P(X=x)=F_X(x)-F_X(x-).\]

这里 \(F_X(x-)=\lim_{u\uparrow x}F_X(u)=P(X<x)\)，即从 x 的左边逼近时已累计的概率。所以 F 的跳跃高度就是某个点的概率。两次硬币的例子：x<0 时 F=0；0≤x<1 时 F=1/4；1≤x<2 时 F=3/4；x≥2 时 F=1。

到达 1 的瞬间，把 X=1 的概率 1/2 也累计进来；实心点表示取到该值。

分布律与密度：两种不同的概率记账方法

离散型只在有限个或能逐个编号的数值 x₁、x₂、……上取值。定义 pₖ=P(X=xₖ)，即第 k 个数值占多少概率；全部 pₖ 合起来叫概率分布律，每项非负、总和为 1。

概率密度 f 是另一种描述：对于有密度的连续型变量，区间概率由 f 在区间内的面积给出。f 本身是一个普通非负函数，单位可理解成“每单位长度分配多少概率”。这是一种定义，不是说每个随机变量都必须有密度。以下把两种记账方法并排对照：

离散型 连续型（有密度时）
描述 \(p_k=P(X=x_k)\) \(f(x)\ge0\)，\(F(x)=\int_{-\infty}^x f(u)\,du\)
归一化 \(\sum_kp_k=1\) \(\int_{-\infty}^{\infty}f(x)\,dx=1\)
区间概率 把区间内的点概率相加 \(P(a<X\le b)=\int_a^bf(x)\,dx\)

如果 CDF 可以由密度积分表示，那么在可导且满足通常积分求导条件的位置，f(x)=F′(x)：累计面积的变化率就是当地的密度。反过来，对 f 积分就累回 F；符号 du 表示积分沿数轴变量 u 进行，u 只是积分中的占位字母。

密度不是点概率。连续型变量有 \(P(X=x)=0\)，但附近一小段的概率约为 \(f(x)\Delta x\)。密度可以大于 1，例如 (0, 0.1) 上均匀分布的密度为 10；总面积仍然是 1。分布函数连续也不一定存在密度，不过本章的常规连续例题都有密度。

只看一个数的分布，无法回答“两次数值同时满足条件”的问题。先把可能取值排成二维表，表格内部是联合分布，沿行列加总是边缘，固定一列并重新归一化是条件分布。

联合分布、边缘分布、条件分布

多个随机变量是对同一结果记录多个分数。例如 X 是第一次骰子点数、Y 是两次点数之和。对 n 个变量 X₁,…,Xₙ，各设一个门槛 x₁,…,xₙ，同时满足所有门槛的概率，定义为它们的联合分布函数 F。公式中的逗号读作“并且”，不是加法：

\[F(x_1,\ldots,x_n)=P(X_1\le x_1,\ldots,X_n\le x_n).\]

若变量离散，还可定义联合分布律 p(x,y)=P(X=x,Y=y)；若有联合密度，则用 f(x,y) 记单位小面积上的概率浓度。边缘分布就是不关心其他变量，只看某一项。把其他门槛放到 +∞，或者枚举 Y 的全部可能值并相加，因为不同 Y 值对应互斥事件；连续时同样把 Y 方向的密度全部积分掉。因此得到：

\[p_X(x)=\sum_yp(x,y),\qquad f_X(x)=\int_{-\infty}^{\infty}f(x,y)\,dy.\]

条件分布是选定一个切片，再归一化。离散时除以切片概率；有联合密度时除以边缘密度：

\[p_{X\mid Y}(x\mid y)=\frac{p(x,y)}{p_Y(y)},\qquad f_{X\mid Y}(x\mid y)=\frac{f(x,y)}{f_Y(y)}\quad\text{（分母为正）}.\]

连续时 P(Y=y)=0，不能直接用这个点概率做分母。先在 Y=y 附近取宽度 Δy 的窄带：其概率约为 fY(y)Δy；再取 X=x 附近宽度 Δx 的小格，联合概率约为 f(x,y)ΔxΔy。用条件概率定义相除，Δy 抵消，条件下小区间概率约为 [f(x,y)/fY(y)]Δx，所以括号内就是条件密度。极限公式在相应的密度条件下、Y 几乎处处成立。多维时完全一样：固定已知坐标，用联合分布除以已知坐标的边缘分布。

用一张表，把联合、边缘、条件实际算一遍
联合概率 p(x,y) Y=0 Y=1 行和 P(X=x)
X=0 0.4 0.1 0.5
X=1 0.2 0.3 0.5
列和 P(Y=y) 0.6 0.4 1

联合看单元格，例如 P(X=1,Y=1)=0.3；边缘看行列和，例如 P(Y=1)=0.4；条件则只保留 Y=1 这一列并归一化，\(P(X=1\mid Y=1)=0.3/0.4=0.75\)。它不等于 P(X=1)=0.5，所以二者不独立。

连续联合密度同样按范围积分；若问矩形区域，可从联合 CDF 扣去不需要的两边，再加回重复扣除的角：

\[\begin{aligned}P(a<X\le b,c<Y\le d)&=F(b,d)-F(a,d)\\&\quad-F(b,c)+F(a,c).\end{aligned}\]

随机变量独立的定义：各自的取值限制不互相提供信息

如果每个变量分别加上任意取值限制，它们同时满足的概率总能拆成各自概率的乘积，就称这些变量相互独立。用“每个变量都不超过各自门槛”的事件表述，等价的检查公式如下。乘积号 ∏ 表示把 j=1 到 n 的所有边缘概率乘起来：

\[X_1,\ldots,X_n\text{ 相互独立}\iff F(x_1,\ldots,x_n)=\prod_{j=1}^nF_{X_j}(x_j)\quad\text{对所有门槛}.\]

离散型可检查联合分布律是否为边缘乘积；有联合密度时检查 \(f(x,y)=f_X(x)f_Y(y)\) 是否几乎处处成立。定义域也要一起检查。只有公式长得像两个函数的乘积、支撑区域却把 x 和 y 绑在一起，仍可能不独立。

三个变量“两两独立”，还不一定“相互独立”

独立公平硬币 X、Y 取 0/1，令 Z=1 表示 X≠Y，否则 Z=0。三个变量的任意一对都独立；例如每个 (X,Z) 组合都占 1/4。但 Z 已由 X、Y 决定：

\[P(X=0,Y=0,Z=0)=1/4\ne(1/2)^3.\]

所以“每一对看起来独立”还不够。相互独立检查的是完整联合分布能否拆成全部边缘的乘积。

做题补充：求函数的分布，先求“过门槛”的概率

令 \(Y=g(X)\)，最稳的入口是 \(F_Y(y)=P(g(X)\le y)\)。若 g 严格单调可微，反函数为 h，常规条件下：

\[f_Y(y)=f_X(h(y))|h'(y)|.\]

绝对值是防止单调递减时算出负密度。比如 \(U\sim U(0,1)\)，\(T=-\ln U\)，则 \(P(T>t)=P(U<e^{-t})=e^{-t}\)（t≥0），所以 T 是参数 1 的指数分布。非单调函数要按各个反函数分支相加，不能只取一个根。

数字特征：用少量数字概括一个分布

分布能回答所有取值问题，但比较两个方案时，我们常先问“平均多少、波动多大”。这就需要期望和方差。多个随机量一起出现时，还要问它们是否一起偏高或偏低，于是从单个量自然走到协方差。

分布是一张完整地图。期望标出重心，方差描述分散程度，协方差描述两个量的线性联动。

数学期望的定义：每个可能的数值，按概率分一份权重

普通平均是“每项同样重要”：1、2、6 的平均为 (1+2+6)/3。如果这些值出现的机会不同，就不能各占 1/3。数学期望把每个可能值乘上它出现的概率，再全部相加；记号 E 表示执行这种概率加权平均，EX 与 E[X] 是同一写法。

设 X 可能取 xₖ，概率为 pₖ。k 是取值清单中的编号，不是另一个随机量。按定义：

定义公式：离散型随机变量的数学期望

\[EX=\sum_kx_kp_k.\]

例如收益 100 元的概率 0.1，收益 0 元的概率 0.9，期望为 100×0.1+0×0.9=10 元。它表示这个分布的平均水平，不保证某一次能得到 10 元，也不是“最可能的值”。

有密度 f 的连续型变量，把数轴切成小段：x 附近一小段概率约为 f(x)Δx，所以这一段对平均的贡献约为 xf(x)Δx。把小段无限细分，加总就成为积分：

连续型的期望公式：概率加权求和的积分版本

\[EX=\int_{-\infty}^{\infty}xf(x)dx.\]

还常把两种情况统一记成 \(EX=\int x\,dF(x)\)。dF 不是“d 乘 F”，而是“按分布 F 的概率权重累计”的记号：离散时就是上面的求和，有密度时就是乘 f(x)dx 后积分。

若希望得到有限的期望，要求 E|X|<∞；|X| 是绝对值，E|X| 是把正负号都去掉后的平均大小。不能拿“正无穷−负无穷”当抵消。非负变量的期望则可定义为 +∞。

函数的期望：先算每次的 g(X)，再按原概率平均

若收益改成 g(X)，只需把每个可能值 x 改成 g(x)，概率没有改变。因此：

\[E[g(X)]=\sum_kg(x_k)p_k\quad\text{或}\quad E[g(X)]=\int g(x)f(x)dx.\]

统一写法是 \(\int g(x)dF(x)\)。多个变量时，用联合分布的概率来加权：\(E[g(X,Y)]=\sum_x\sum_yg(x,y)p(x,y)\)，有密度就换成二重积分。一般不必先另求 g(X) 的分布。注意这不等于先取平均再代入：例如公平取 ±1 时 EX=0，但 E[X²]=1，而 (EX)²=0。

方差的定义：平均以后，偏差还剩多大？

只知道均值看不出波动。两个分布都可能均值 0，一个永远取 0，另一个等概率取 ±100。我们先把每次值减去均值，再平方消掉正负抵消，最后求平均；得到的量叫方差，记作 DX 或 Var(X)。这里设 E[X²] 有限，并用 μ=EX 暂时缩短写法：

定义公式：方差是“偏离自身均值的平方”的期望

\[DX=E[(X-\mu)^2],\qquad\mu=EX.\]

μ 是确定的平均数，不是另一个随试验变化的变量。展开平方，再按期望平均，便得到常用计算式：

\[\begin{aligned}DX&=E[X^2-2\mu X+\mu^2]\\&=E[X^2]-2\mu EX+\mu^2\\&=E[X^2]-(EX)^2.\end{aligned}\]

所以“先平方再平均”减去“先平均再平方”，是在计算方差，不是另起一个新定义。收益单位是元时方差单位为元²；平方根 √DX 叫标准差，单位回到元。D 越大表示整体偏离越强，但不意味着每一次都偏得远。

同样由定义，平移 b 不改变离均值的距离，缩放 a 会把每个偏差乘 a，再平方：

\[D(aX+b)=E[(aX+b-(a\mu+b))^2]=a^2E[(X-\mu)^2]=a^2DX.\]

因此 DX=0 等价于 X=EX 几乎必然：非负的偏差平方如果在某个正概率事件上为正，其平均不可能为 0。方差为 0 允许概率为 0 的例外，并不要求逐个样本结果完全相同。

期望的线性性：拆平均不需要独立

a、b 是确定常数，X、Y 有有限期望。每次先算 aX+bY 再平均，与把两个平均分别缩放后相加相同。这条性质叫期望的线性性：

\[E[aX+bY]=aEX+bEY.\]

例如离散情形按联合概率展开：\(\sum_{x,y}(ax+by)p(x,y)\) 拆成两个和；把第一个和里的 Y 求完得到 X 的边缘概率，第二个同理。这一步没把联合概率拆成乘积，故不需要独立。

协方差的定义：两个量的偏差是同向还是反向？

设 μX=EX、μY=EY，X、Y 的二阶矩有限。一次试验里，若 X、Y 都高于各自均值，或都低于各自均值，偏差乘积为正；若一个高一个低，乘积为负。把这个乘积平均，定义为协方差 cov(X,Y)：

\[\operatorname{cov}(X,Y)=E[(X-\mu_X)(Y-\mu_Y)].\]

展开两个括号，μX、μY 都是可提出平均之外的常数，所以：

\[\operatorname{cov}(X,Y)=E[XY]-\mu_YEX-\mu_XEY+\mu_X\mu_Y=E[XY]-EX\,EY.\]

它主要量化线性同向变化，正负偏差也可能互相抵消；协方差 0 不代表任何关系都没有。下面会给出一个非线性反例。

为什么“和的方差”里要多出一项？

对 aX+bY，去掉均值后的偏差是 a(X−μX)+b(Y−μY)。对它平方，除了两个平方，还会多出两倍交叉乘积，因此：

\[D(aX+bY)=a^2DX+b^2DY+2ab\operatorname{cov}(X,Y).\]

独立时 E[XY]=EX·EY，协方差为 0，可以直接相加；其实只要协方差为 0 就能这么加，并不必须独立。这解释了为什么“平均可直接拆，方差却要先检查关系”。

相关系数：给协方差去掉单位

如果 X 从米换成厘米，协方差的数值会随之改变。为了只看线性关系强弱，而不受单位影响，把协方差除以两边各自的标准差，定义相关系数 ρXY（希腊字母 rho）：

\[\rho_{XY}=\frac{\operatorname{cov}(X,Y)}{\sqrt{DX}\sqrt{DY}},\qquad DX>0,\ DY>0.\]

分母的两个标准差消除了尺度。由本节稍后的 Cauchy–Schwarz 不等式，协方差平方≤DX·DY，所以 −1≤ρ≤1。ρ>0 表示总体同向，ρ<0 表示总体反向，ρ=0 叫不相关。若 |ρ|=1，两量在概率 1 意义下具有精确线性关系；若某一方方差为 0，这个比值没有定义。

不相关不等于独立。取 \(X\sim U(-1,1)\)，\(Y=X^2\)。由对称性 EX=EX³=0，所以 cov(X,Y)=0。直接检验：事件 |X|<1/2 与 Y<1/4 是同一事件，概率为 1/2，它们同时发生的概率是 1/2，而不是独立时应有的 1/4，所以不独立。联合正态是能把不相关升级为独立的重要额外条件；一般分布不能这样推。

k 阶原点矩是 \(E[X^k]\)，k 阶中心矩是 \(E[(X-EX)^k]\)；二阶中心矩就是方差。多变量还有混合矩，比如 \(E[X^2Y]\)。需要相应的绝对矩有限时，再进行下面的求导、换序等操作。

指示变量：把“发生没发生”变成 0/1

\[I_A=\mathbf1_A=\begin{cases}1,&A\text{ 发生},\\0,&A\text{ 不发生}.\end{cases}\qquad EI_A=1\cdot P(A)+0\cdot P(A^c)=P(A).\]

若要统计满足某条件的个数，把每个对象是否满足写成一个 I，再相加。期望的线性性直接给：

\[E\left[\sum_{j=1}^nI_{A_j}\right]=\sum_{j=1}^nP(A_j).\]

各事件即使相互影响，这个等式仍成立，因为拆期望不需要独立。比如一副打乱的 n 顶帽子，第 j 人拿对概率 1/n，拿对总人数的期望就是 n×(1/n)=1；这和例 1.2 的 Poisson(1) 极限相呼应。例 1.3 也用同一招数孤立点。

非负量的另一个均值公式：按高度一层层累计

若 K 是非负整数，K=k 时，“K>0、K>1、……、K>k−1”恰好有 k 件成立，所以 K=∑ⱼ₌₀∞1{K>j}。取期望得到：

\[EK=\sum_{j=0}^{\infty}P(K>j).\]

连续的非负 T 也类似：每次实现值为 t 时，下面 0 到 t 的每层都贡献高度 1，故 \(T=\int_0^\infty\mathbf1_{\{T>u\}}du\)。平均后得到 \(ET=\int_0^\infty P(T>u)du\)。非负项没有正负抵消，可这样交换累计顺序。几何与指数分布会实际用到它。

两个量有一项协方差，三个量就有三对。为避免漏掉配对，把它们按行列整理成矩阵；先把它当表格读，后面的矩阵公式只是把加权求和压缩成一行。

均值向量与协方差矩阵

\[\boldsymbol\mu=(EX_1,\ldots,EX_n)^\top,\qquad B_{jk}=\operatorname{cov}(X_j,X_k).\]

B 把所有配对的联动整理成表：对角线是各自方差，非对角线是协方差。B 对称且半正定，因为任意加权和的方差 \(\boldsymbol a^\top B\boldsymbol a\ge0\)。它不代表所有分布信息，但在联合正态情形下，均值与 B 就足以确定分布。

矩阵的作用是把多项方差公式压缩成一行。任意确定权重 a₁,…,aₙ 都满足：

\[D\left(\sum_ja_jX_j\right)=\sum_ja_j^2DX_j+2\sum_{j<k}a_ja_k\operatorname{cov}(X_j,X_k)=\boldsymbol a^\top B\boldsymbol a.\]

展开 \(E[(\sum_ja_j(X_j-EX_j))^2]\) 就能得到它。第二章把 Xⱼ 换成若干时刻的 X(tⱼ)，使用的还是同一公式。

二阶矩有限，为什么相关与一阶矩也算得动？

对二阶矩有限的实随机变量 U,V，先由 2|UV|≤U²+V² 知道 E|UV| 有限。此时有 Cauchy–Schwarz 不等式：

\[|E[UV]|^2\le E[U^2]E[V^2].\]

当 EV²>0，展开非负量 \(E[(U-cV)^2]\)，取 \(c=E[UV]/E[V^2]\)，便得到上式；EV²=0 时 V=0 几乎必然，结论同样成立。复变量把一个因子取共轭，平方改成模长平方，也成立。

令 U=|X|、V=1，得到 \(E|X|\le\sqrt{E|X|^2}\)。令 U=|X|、V=|Y|，说明两个二阶矩有限时 E|XY| 也有限。因此只要各状态有有限二阶矩，就能谈它们的相关和协方差；第二章的二阶矩过程正是利用这点。

Markov 与 Chebyshev：只知道均值或方差，也能给尾部概率封顶

\[P(|X|\ge\varepsilon)\le\frac{E|X|^r}{\varepsilon^r}\quad(r>0,\ \varepsilon>0),\]\[\boxed{P(|X-EX|\ge\varepsilon)\le\frac{DX}{\varepsilon^2}}.\]

第一式的理由：落在“大于门槛”的那一块，每个 \(|X|^r\) 都至少是 εʳ，所以总平均至少为 \(\varepsilon^rP(|X|\ge\varepsilon)\)。第二式把 X 换成 X−EX，取 r=2。概率上界算出大于 1 时，只能说明估计很松，实际可取上界 1。

例：独立测量噪声的方差为 9，100 次平均的方差为 9/100。平均偏离真实均值至少 1 的概率 ≤0.09。方差趋 0 → 偏离概率趋 0，就是后面大量证明的发动机。

记忆抓手：期望可直接拆；方差先查协方差；证明“越来越接近均值”，先想 Chebyshev。

桥接工具：独立随机量相加，为什么出现卷积？

设 X、Y 独立，S=X+Y。离散时，S=k 可以由所有 \((X=j,Y=k-j)\) 互斥情况组成，所以：

\[P(S=k)=\sum_jP(X=j)P(Y=k-j).\]

有密度时同样先固定 X=x；Y 只需补到 s−x，按所有 x 加权积分：

\[f_S(s)=\int_{-\infty}^{\infty}f_X(x)f_Y(s-x)dx.\]

这叫卷积。若两项都非负，s>0 时积分只需从 0 到 s，因为区间外至少一个密度为 0。这里相乘用了独立；不独立时要保留联合密度 \(f_{X,Y}(x,s-x)\)，不能拆开。

例如两个独立 U(0,1) 相加，密度是满足 0<x<1、0<s−x<1 的区间长度：0<s<1 时为 s，1≤s<2 时为 2−s，其他为 0。独立和的密度要积分，特征函数却只需相乘；这正是下一节变换工具的价值。

分布实例 / 概率公式、平均与方差怎样得来

每一种分布，都从一个明确的问题开始

已经会算平均与波动，下面才来认识常用的概率模型。它们分别回答“固定次数成功几次”“等到成功要多久”“一段时间发生几次”等不同问题。先根据场景和假设选模型，再推概率与均值方差；不必先背整张公式表。

下面不把“密度、均值、方差”当成三个互不相干的结论。先说变量在记录什么、模型假定什么，再推导概率，最后用刚学过的期望与方差定义计算。每个小节中的字母重新就地说明。

先区分三种话：“定义”是在给一种对象起名字；“模型假设”是在决定用什么规律描述现象，并不能由概率公理强迫现实满足；“推导”是在这些条件成立后，把结论算出来。比如正态的钟形是模型选择，而它前面的归一化常数可以计算出来。
① Bernoulli 与二项：一次成功没成功，n 次共成功几个？

变量、条件与名称

先做一次只有两种结果的试验，用随机变量 B 记录：成功取 1，失败取 0。记 p 为成功概率（0≤p≤1），q=1−p 为失败概率。这种 0/1 分布就叫Bernoulli 分布，读作伯努利分布。

Bernoulli 分布律：把模型中规定的两个概率写出来

\[P(B=1)=p,\qquad P(B=0)=q=1-p.\]

这两条不是根据其他信息“算出”p，而是用 p 表示这次试验本来的成功机会。既然只取 0 和 1，按期望定义逐项算：

\[EB=0\cdot q+1\cdot p=p,\qquad E[B^2]=0^2q+1^2p=p,\]\[DB=E[B^2]-(EB)^2=p-p^2=p(1-p).\]

所以成功概率本身就是 0/1 变量的平均；p=0 或 p=1 时没有随机波动，方差为 0。

从一次试验到 n 次：二项概率怎样来？

现在独立重复 n 次，每次成功概率仍为 p。n 是事先确定的试验总次数；随机变量 K 记录成功总次数；k 是 K 某一个可能取到的整数，0≤k≤n。这时 K 的分布叫二项分布，记作 K~Bin(n,p)。

例如 n=3，恰好 k=2 次成功的序列是“成功成功失败、成功失败成功、失败成功成功”。每个指定序列的概率是 p²q，三种序列互斥，所以总概率是 3p²q。

一般情形：先从 n 个位置里选出哪 k 个成功，有组合数 C(n,k) 种；每个指定序列由独立性得到 pᵏqⁿ⁻ᵏ；再把互斥序列相加：

二项分布的概率质量公式（离散点概率）

\[P(K=k)=\binom nkp^kq^{n-k},\qquad k=0,1,\ldots,n.\]

所有概率相加是 (p+q)ⁿ=1，正是二项式展开。p=0、1 时按“永远失败/永远成功”的退化情形理解即可。

它的均值与方差怎样算？

令 Bⱼ 是第 j 次是否成功，K=B₁+…+Bₙ。每个 EBⱼ=p、DBⱼ=pq；期望直接相加，独立变量的方差也相加：

\[EK=\sum_{j=1}^nEB_j=np,\qquad DK=\sum_{j=1}^nDB_j=npq.\]

结论的含义：平均成功次数是“次数×单次概率”。n=3、p=0.4 时，恰好成功 2 次的概率为 3×0.4²×0.6=0.288，平均成功数为 1.2，方差 0.72。平均值允许是小数，但一次真实计数始终是整数。试验不独立或成功概率不同，就不能原样套二项模型。

② Poisson：很多次独立小机会，合起来发生了几次？

变量、参数与模型来源

随机变量 K 记录某段范围内发生的总次数，只能取 0,1,2,…。参数 λ（希腊字母 lambda）是这段内的平均总次数，λ>0。我们可以从二项模型推导一种极限分布：把范围分成 n 个独立小机会，每次成功概率设为 λ/n，让 n 越来越大，平均次数 n×(λ/n)=λ 始终不变。

注意，“机会很多且稀疏”还不够，推导还用了独立与相同小概率。不能说任何一段计数都必然服从 Poisson。

概率里的 e⁻λ 与 k! 从哪里来？

对固定的次数 k，二项概率可以重排为：

\[\begin{aligned}P(K_n=k)&=\binom nk(\lambda/n)^k(1-\lambda/n)^{n-k}\\&=\frac{\lambda^k}{k!}\left[\prod_{j=0}^{k-1}(1-j/n)\right](1-\lambda/n)^n(1-\lambda/n)^{-k}.\end{aligned}\]

n→∞ 时，方括号中只有固定 k 项，每项趋 1；最后一项趋 1；中间的 (1−λ/n)ⁿ 趋 e⁻λ。这条指数极限可由 n·ln(1−λ/n)→−λ 得到。因此极限概率为：

Poisson 分布律：稀疏二项计数的极限公式

\[P(K=k)=e^{-\lambda}\frac{\lambda^k}{k!},\quad k=0,1,2,\ldots\]

把具有这组概率的分布定义为 Poisson(λ)。它的总概率是 \(e^{-\lambda}\sum_{k=0}^{\infty}\lambda^k/k!=e^{-\lambda}e^\lambda=1\)，所以这确实是一组合法概率。

为什么均值和方差都恰好是 λ？

先按定义求平均。k=0 没有贡献；k/k!=1/(k−1)!，拿出一个 λ，再令 r=k−1：

\[EK=e^{-\lambda}\sum_{k=1}^\infty\frac{k\lambda^k}{k!}=\lambda e^{-\lambda}\sum_{r=0}^\infty\frac{\lambda^r}{r!}=\lambda.\]

二阶矩直接算 k² 不太简洁，先算 k(k−1)，能再消去两个阶乘因子：

\[E[K(K-1)]=e^{-\lambda}\sum_{k=2}^\infty\frac{\lambda^k}{(k-2)!}=\lambda^2.\]

因为 K²=K(K−1)+K，得到 EK²=λ²+λ，最后减掉均值平方：

\[DK=\lambda^2+\lambda-\lambda^2=\lambda.\]

结论的含义：总量平均越大，波动方差也随之增大。若这一段平均发生 3 次，即 λ=3，那么一次都没有的概率是 e⁻³≈0.0498，不是“平均 3 次所以一定有 3 次”。第二章若用每分钟速率 r 描述长度 t 的时间段，这里的参数就应换成 λ=rt；分布的“总次数参数”与过程的“速率”要分开。

③ 几何：一直试到第一次成功，要试几次？

先固定计数约定，再写概率

各次试验独立，每次成功概率 p∈(0,1]，q=1−p。随机变量 X 记录第一次成功为止的总试验次数，包括成功那一次，所以从 1 开始。

X=k 的意思恰好是“前 k−1 次全失败，第 k 次成功”。将这个指定序列的概率相乘，就得到：

从 1 开始的几何分布律

\[P(X=k)=q^{k-1}p,\qquad k=1,2,\ldots\]

这组概率相加为 \(p\sum_{j=0}^\infty q^j=p/(1-q)=1\)。它因使用等比级数而得名“几何”。

均值 1/p，不是靠猜“平均成功一次要几次”

X>j 意味着前 j 次全失败，概率 qʲ。用非负整数的尾概率均值公式，逐层累加：

\[EX=\sum_{j=0}^\infty P(X>j)=\sum_{j=0}^\infty q^j=\frac1{1-q}=\frac1p.\]

平方同样能逐层拆：整数 k²=1+3+…+(2k−1)，所以 \(EX^2=\sum_{j=0}^\infty(2j+1)P(X>j)\)。对等比级数求导后乘 q，得到 \(\sum_{j=0}^\infty jq^j=q/(1-q)^2\)，于是：

\[E[X^2]=\frac{2q}{p^2}+\frac1p=\frac{2-p}{p^2},\qquad DX=\frac{2-p}{p^2}-\frac1{p^2}=\frac{1-p}{p^2}.\]

结论的含义：p 越小，等得越久、波动也越大。p=1/2 时，平均试 2 次、方差 2；恰好第 3 次成功的概率是 (1/2)³=1/8。

若只数成功前的失败次数，令 Y=X−1，则 P(Y=k)=pqᵏ（k 从 0 开始），EY=1/p−1=q/p，DY=DX。两种都叫几何分布，必须先读计数约定；第二章的随机截止时间计数采用后一种。

④ 均匀：等长区间应有相同概率，公式怎样确定？

模型假设决定密度形状，概率总和决定常数

随机变量 X 的取值只在 a 到 b 之间，a、b 是两个固定端点且 a<b。“均匀”是假设区间里每一段等长的小段有相同概率。因此密度应是一个常数 c。令 L=b−a 表示区间长度，总概率为 1 要求 cL=1，所以 c=1/L。

均匀分布 U(a,b) 的密度公式

\[f_X(x)=\begin{cases}1/(b-a),&a<x<b,\\0,&\text{其他}.\end{cases}\]

fX(x) 是位置 x 的密度，不是 P(X=x)。在 a≤u<v≤b 时，区间概率是高度乘长度：\(P(u<X<v)=(v-u)/(b-a)\)。对门槛 x 左边的面积累计，得到 CDF：

\[F_X(x)=\begin{cases}0,&x<a,\\(x-a)/(b-a),&a\le x\le b,\\1,&x>b.\end{cases}\]

均值与方差实际积分一次

\[EX=\frac1L\int_a^b x\,dx=\frac{b^2-a^2}{2L}=\frac{a+b}{2}.\]

均值是区间中点。计算方差时以中点为原点，令 z=x−(a+b)/2，积分范围就变成 −L/2 到 L/2：

\[DX=\frac1L\int_{-L/2}^{L/2}z^2dz=\frac1L\left[\frac{z^3}{3}\right]_{-L/2}^{L/2}=\frac{L^2}{12}.\]

结论的含义：区间整体平移只改变均值，不改变方差；长度放大 2 倍，方差放大 4 倍。例如 U(0,10) 中，落在 (2,4) 的概率是 2/10，平均为 5，方差为 100/12。U(0,1) 的特殊便利是 F(x)=x（0≤x≤1），概率与数值门槛恰好一致。

⑤ 指数：假设等待没有记忆，为什么会得到 e⁻λt？

先规定变量与无记忆假设

随机变量 T 是非负等待时间，t 是我们已等待的固定时长。定义生存函数 S(t)=P(T>t)，意思是“等了 t 还没发生”。假设刚开始不会瞬间发生，S(0)=1，S 连续，并假设等待最终会结束且一单位后仍有正概率继续等待，即 0<S(1)<1；无记忆性表示“已经等了 s，接下来再等 t 的机会和刚开始相同”：

\[P(T>s+t\mid T>s)=P(T>t).\]

左边按条件概率定义等于 S(s+t)/S(s)，所以无记忆要求变成 S(s+t)=S(s)S(t)。这里 s、t 是任意非负固定时长，不是随机变量。

由这条要求推导生存函数

以选定的一单位时间记作 1：重复相乘得到 S(n)=S(1)ⁿ；因为 S(1)=S(1/n)ⁿ，有 S(1/n)=S(1)¹⁄ⁿ；进而对任意非负有理数 m/n，S(m/n)=S(1)ᵐ⁄ⁿ。连续性把它扩展到全部非负实数。

记 λ=−ln S(1)>0，就有 S(t)=e⁻λt。λ 叫速率参数，单位是 1/时间。这是由无记忆模型推出来的形状，不是在说所有寿命或等待都无记忆。

指数分布 Exp(λ) 的生存函数、CDF 与密度

\[S(t)=e^{-\lambda t},\quad F_T(t)=1-e^{-\lambda t}\quad(t\ge0),\]\[f_T(t)=F_T'(t)=\lambda e^{-\lambda t}\quad(t>0),\qquad f_T(t)=0\quad(t<0).\]

导数前的 λ 来自对 e⁻λt 使用链式法则；同样保证密度积分为 1。

均值与方差如何分部积分？

先按期望定义计算，边界项 t·e⁻λt 在 0 与 ∞ 都为 0：

\[ET=\int_0^\infty t\lambda e^{-\lambda t}dt=[-te^{-\lambda t}]_0^\infty+\int_0^\infty e^{-\lambda t}dt=\frac1\lambda.\]

二阶矩再做一次同样操作：

\[E[T^2]=\int_0^\infty t^2\lambda e^{-\lambda t}dt=2\int_0^\infty te^{-\lambda t}dt=\frac2{\lambda^2},\]\[DT=E[T^2]-(ET)^2=\frac2{\lambda^2}-\frac1{\lambda^2}=\frac1{\lambda^2}.\]

结论的含义：速率越大，平均等待越短。λ=2/分钟时，平均等待 1/2 分钟，仍等超过 1 分钟的概率为 e⁻²≈0.1353。无记忆性也可代回验证：e⁻λ(s+t)/e⁻λs=e⁻λt，第二章的指数时钟竞争用的就是它。

⑥ 正态：钟形是一种模型，前面的常数与均值方差可以推出来

先说明我们选择了什么形状

先用 Z 表示一个以 0 为中心、左右对称的误差。选择 g(z)=c·e⁻ᶻ²⁄² 作为密度形状：偏差平方越大，密度下降越快。这个钟形选择叫标准正态模型；概率公理并不要求所有误差都长成它。c 是未知正数，要用总面积为 1 算出来。

√(2π) 从哪里来？把一维积分平方后变成平面面积

令 \(I=\int_{-\infty}^{\infty}e^{-z^2/2}dz\)。I² 等于 x、y 平面上的积分。改用半径 r 与角度 θ：x=r cosθ、y=r sinθ，小扇形的面积为 r·dr·dθ：

\[\begin{aligned}I^2&=\int_{\mathbb R^2}e^{-(x^2+y^2)/2}dxdy\\&=\int_0^{2\pi}d\theta\int_0^\infty e^{-r^2/2}r\,dr=2\pi.\end{aligned}\]

r 的积分换元 u=r²/2 后就是 ∫₀∞e⁻ᵘdu=1。I 为正，所以 I=√(2π)，总面积 cI=1 要求 c=1/√(2π)。这里 x、y 仅是平面积分坐标，r 是到原点的距离，θ 是角度，不是新加的随机量。

标准正态 N(0,1) 的密度：把钟形归一化

\[g(z)=\frac1{\sqrt{2\pi}}e^{-z^2/2},\qquad z\in\mathbb R.\]

为什么名称中的 0、1 恰好是均值与方差？

z·g(z) 在 0 两边大小相同、符号相反，积分抵消，所以 EZ=0。又因为 g′(z)=−zg(z)，分部积分得到：

\[E[Z^2]=\int_{-\infty}^{\infty}z^2g(z)dz=-[zg(z)]_{-\infty}^{\infty}+\int_{-\infty}^{\infty}g(z)dz=1.\]

因此 DZ=1−0²=1。现在希望中心为某个固定 μ（mu），标准差为固定 σ>0（sigma），就令 X=μ+σZ。由均值线性性与方差缩放公式，EX=μ、DX=σ²；按变量变换，z=(x−μ)/σ，每段长度还要除以 σ：

一般正态 N(μ,σ²) 的密度：标准钟形的平移与缩放

\[f_X(x)=\frac1\sigma g\!\left(\frac{x-\mu}{\sigma}\right)=\frac1{\sqrt{2\pi\sigma^2}}\exp\!\left[-\frac{(x-\mu)^2}{2\sigma^2}\right].\]

结论的含义：μ 控制钟形中心；σ 控制宽度，名称的第二个参数写的是方差 σ²，不是标准差 σ。把 (X−μ)/σ 变回 Z，叫标准化。

标准正态的分布函数另外命名为 Φ（大写 phi）：\(\Phi(x)=\int_{-\infty}^x g(z)dz\)。它表示标准钟形在 x 左边的面积，不是密度 g。后面的多维正态、例 1.8 的混合分布反例会用到这个名字。

⑦ Gamma：等够 n 次指数等待，密度怎样累积出来？

先从整数 n 的明确场景推起

T₁,…,Tₙ 是相互独立、速率相同为 β>0 的指数等待。β 读 beta；Sₙ=T₁+…+Tₙ 表示等够 n 段的总时间。第一段密度 f₁(x)=βe⁻βx。现在用独立和的卷积，假定 n−1 段的密度已经求出，再加上最后一段：

\[\begin{aligned}f_n(x)&=\int_0^x\frac{\beta^{n-1}u^{n-2}e^{-\beta u}}{(n-2)!}\,\beta e^{-\beta(x-u)}du\\&=\frac{\beta^ne^{-\beta x}}{(n-2)!}\int_0^xu^{n-2}du\\&=\frac{\beta^nx^{n-1}e^{-\beta x}}{(n-1)!},\quad x>0.\end{aligned}\]

这一步适用于 n≥2，n=1 已经是起点，所以归纳得到了全部正整数 n。xⁿ⁻¹ 来自对多个等待相加时出现的积分，不是凭空放进去的项。

为什么引入 Γ 函数与形状参数 α？

想把这组密度推广到不只整数的形状 α>0（alpha），就需要把 (n−1)! 延伸成一个函数。定义Gamma 函数：

\[\Gamma(\alpha)=\int_0^\infty v^{\alpha-1}e^{-v}dv.\]

这是一个以 α 为输入、以正数为输出的普通函数，Γ 不是随机变量。分部积分给出：

\[\Gamma(\alpha+1)=[-v^\alpha e^{-v}]_0^\infty+\alpha\int_0^\infty v^{\alpha-1}e^{-v}dv=\alpha\Gamma(\alpha).\]

Γ(1)=1，逐次递推便有 Γ(n)=(n−1)!。对候选形状 xᵅ⁻¹e⁻βx，令 v=βx，可以算出总面积 Γ(α)/βᵅ。因此前面的常数应取 βᵅ/Γ(α)，使总面积等于 1：

Gamma(α,β) 的密度定义（形状 α，速率 β）

\[f(x)=\frac{\beta^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\beta x},\quad x>0;\qquad f(x)=0\quad x\le0.\]

α=n 是前面真正等待 n 次的模型；α 不是整数时，同一个密度家族仍合法，但不能硬解释成“等待非整数个事件”。

均值与方差：让 Γ 的输入各提高一次、两次

密度积分里多乘一次 x，幂次提高 1；将同一个 Γ 积分的参数从 α 换成 α+1：

\[EX=\frac{\beta^\alpha}{\Gamma(\alpha)}\frac{\Gamma(\alpha+1)}{\beta^{\alpha+1}}=\frac\alpha\beta.\]

多乘 x² 就把输入提高 2：

\[E[X^2]=\frac{\Gamma(\alpha+2)}{\beta^2\Gamma(\alpha)}=\frac{\alpha(\alpha+1)}{\beta^2},\quad DX=\frac{\alpha(\alpha+1)-\alpha^2}{\beta^2}=\frac\alpha{\beta^2}.\]
补足 χ² 要用的工具：同速率 Gamma 相加，形状为什么相加？

若 U、V 独立，分别为 Gamma(a,β)、Gamma(b,β)，a、b 是两个正形状，β 是共同速率。卷积先给出：

\[f_{U+V}(x)=\frac{\beta^{a+b}e^{-\beta x}}{\Gamma(a)\Gamma(b)}\int_0^xu^{a-1}(x-u)^{b-1}du.\]

令 v=u/x，这个积分等于 \(x^{a+b-1}\int_0^1v^{a-1}(1-v)^{b-1}dv\)。最后这个积分等于 Γ(a)Γ(b)/Γ(a+b)，原因也可以在此验证：把 Γ(a)Γ(b) 写成两个正变量 u,w 的二重积分，再取总量 r=u+w 和比例 v=u/(u+w)，小面积缩放为 r·dr·dv：

\[\begin{aligned}\Gamma(a)\Gamma(b)&=\int_0^\infty\!\int_0^\infty u^{a-1}w^{b-1}e^{-(u+w)}dudw\\&=\left(\int_0^\infty r^{a+b-1}e^{-r}dr\right)\left(\int_0^1v^{a-1}(1-v)^{b-1}dv\right).\end{aligned}\]

第一个括号就是 Γ(a+b)。代回卷积，分母约掉 Γ(a)Γ(b)，恰好留下 Gamma(a+b,β) 的密度。这证明了相加规则；共同速率与独立两个条件都不能丢。

结论的含义：整数 n 时，平均总等待为 n 倍的单段平均，方差也因独立相加为 n 倍的单段方差。例如等 3 次、每次速率 2/分钟，平均等待 3/2 分钟、方差 3/4 分钟²。注意本套教程的第二参数始终是速率 β；若用“尺度”参数 θ，它等于 1/β。

⑧ χ²：把独立标准正态平方后相加，为什么也是 Gamma？

先给出这个分布的定义

取 n 个相互独立的标准正态 Z₁,…,Zₙ，令 Q=Z₁²+…+Zₙ²。χ²(n)（卡方分布）定义为这个 Q 的分布，n 叫自由度，在这里就是独立平方项的个数。

先只看 W=Z²。w>0 时，Z²≤w 等价于 −√w≤Z≤√w，因此 CDF 是这个区间的标准正态概率。对 w 求导，两侧端点各贡献一项：

\[f_W(w)=\frac{g(\sqrt w)+g(-\sqrt w)}{2\sqrt w}=\frac{e^{-w/2}}{\sqrt{2\pi w}},\quad w>0.\]

它正是 Gamma(1/2,1/2) 的密度，因为 Γ(1/2)=√π（对 Γ 积分作 v=z²/2 的换元，也能由刚才的高斯积分得到）。

同速率的独立 Gamma 相加，形状参数相加：上一小节已给出卷积的完整证明。所以 n 个这样的平方相加，得到 Gamma(n/2,1/2)，即：

\[\chi^2(n)=\operatorname{Gamma}(n/2,1/2).\]

最后将 α=n/2、β=1/2 代入刚刚推导的 Gamma 均值方差式，而不是另背一对数：

\[EQ=\frac{n/2}{1/2}=n,\qquad DQ=\frac{n/2}{(1/2)^2}=2n.\]

结论的含义：标准正态本来能正能负，平方和却只能非负。χ² 适合描述这种“标准化误差的平方总量”，不是描述正负误差本身。

现在这些公式可以串起来了：一次成功 → Bernoulli；成功总数 → 二项；稀疏二项极限 → Poisson；第一次成功的试验数 → 几何；无记忆等待 → 指数；指数等待之和 → Gamma；正态误差平方和 → χ²。均匀与正态则是先明确形状模型，再计算归一化、均值和方差。

特征函数：给一个分布换一种编码

刚才用卷积求独立和，每增加一个变量，求和或积分就更复杂。有没有一种表示，能把“随机量相加”变成“普通函数相乘”？特征函数就是为此引入的。先跟两点分布算一次编码，再看它为什么能还原概率和读取矩。

两个独立随机量相加时，密度要做卷积，很麻烦。换成特征函数后，直接相乘。它像一种不会丢信息的“换语言”。

复指数不是新概率：先用欧拉公式看懂它\[e^{iv}=\cos v+i\sin v,\quad |a+ib|=\sqrt{a^2+b^2},\quad\overline{a+ib}=a-ib.\]

所以 \(|e^{iv}|=1\)，可视为单位圆上角度 v 的箭头。共轭把虚部反号，相当于关于实轴翻转；\(e^{-iv}=\overline{e^{iv}}\)。含复数的期望分别平均实部与虚部即可，不会额外改变概率规则。

对实参数 t 求导仍用链式法则：\(\frac d{dt}e^{itx}=ixe^{itx}\)。二次求导出现 i²=−1，正是后面二阶矩负号的来源。

特征函数的定义：把每个可能数值变成箭头，再平均

给定实随机变量 X。另取一个人为选择的实数参数 t，它在本章不是时间、也不是另一个随机变量。先算每次结果对应的复数 eⁱᵗˣ，再按 X 的概率分布求期望。把得到的确定函数命名为X 的特征函数，记作 φX(t)（小写 phi）。下标 X 说明编码的是哪个变量。

特征函数定义；第二个等号来自欧拉公式与期望线性性

\[\boxed{\varphi_X(t)=E[e^{itX}]=E[\cos(tX)]+iE[\sin(tX)]},\qquad t\in\mathbb R.\]

固定一个 t，把每个可能的 X 变成单位圆上一个箭头 \(e^{itX}\)，然后按概率把这些箭头平均。t 改变，箭头旋转快慢改变。一个 t 只给两个实数；所有 t 的结果合在一起，完整编码整个分布。

两点分布 P(X=0)=1−p、P(X=1)=p 中，X=0 对应箭头 e⁰=1，X=1 对应箭头 eⁱᵗ，因此按期望定义得到 φ(t)=(1−p)×1+p×eⁱᵗ。因为 \(|e^{itX}|=1\)，这个期望对任何实随机变量都存在；期望 EX 却可能不存在。这是它比矩母函数 \(M(s)=E[e^{sX}]\) 更通用的原因。两者别混用。

动手看 · 概率加权的两个箭头

灰箭头：1 与 eⁱᵗ；绿色箭头：(1−p)·1+p·eⁱᵗ。平均箭头始终在单位圆内。

一维特征函数：每条性质都在干什么

“正定”不是每个 \(\varphi(t)\ge0\)（它可能是复数），而是这整个二次型非负。判定定理说：一个在实轴连续、\(\varphi(0)=1\) 的复值函数，是特征函数当且仅当它正定。仅仅模长≤1并不够。

“可以交换极限与期望”的一个安全使用条件

若随机量 Zₙ 几乎处处趋 Z，而且始终有 \(|Z_n|\le H\)、EH<∞，则 \(EZ_n\to EZ\)。这叫支配收敛：所有可能的巨大值都被同一个可积的 H 控住，便不会出现“极少数巨大值撑住平均”的漏洞。

这里 \(|e^{ihX}-1|\le2\)，H=2 就是可积上界，所以它的期望随 h→0 也趋 0。反之，仅仅逐结果趋 0，不加这个条件，期望未必趋 0；收敛反例会实际展示。

在 0 求导，怎样把矩读出来？

如果 E|X|² 有限，可在期望内对 t 求两次导数：

\[\varphi'(t)=E[iXe^{itX}],\qquad\varphi''(t)=E[-X^2e^{itX}].\]

因为指数模长为 1，所需上界分别是 |X| 和 X²，已有相应可积性。让 t=0，指数因子变 1，就得到 \(\varphi'(0)=iEX\)、\(\varphi''(0)=-E[X^2]\)。更高阶同理。只有满足所需矩条件后，才用这条求导捷径。

分布与特征函数一一对应，故两个特征函数完全相同就能断定两个分布相同。若特征函数绝对可积，可用反演式恢复一个连续版本的密度：

\[f(x)=\frac1{2\pi}\int_{-\infty}^{\infty}e^{-itx}\varphi(t)\,dt.\]

算 EX 与 DX 时尤其注意负号：\(EX=\varphi'(0)/i\)，\(E[X^2]=-\varphi''(0)\)，\(DX=-\varphi''(0)-(\varphi'(0)/i)^2\)。

多维特征函数的定义：给每个随机量配一个参数

现在 X₁,…,Xₙ 是 n 个随机变量，粗体 X 表示由它们组成的向量；粗体 t=(t₁,…,tₙ) 是我们指定的 n 个实数参数。把 tⱼXⱼ 全部相加、放进复指数再求平均，定义为它们的联合特征函数：

\[\varphi_{\boldsymbol X}(\boldsymbol t)=E\exp\!\left(i\sum_{j=1}^nt_jX_j\right).\]

仍满足在原点为 1、模长≤1、\(\varphi(-\boldsymbol t)=\overline{\varphi(\boldsymbol t)}\)、在 \(\mathbb R^n\) 上一致连续。其余性质可以直接从定义读出来：

  • 线性组合：\(Y=\sum_ja_jX_j\Rightarrow\varphi_Y(t)=\varphi_{\boldsymbol X}(a_1t,\ldots,a_nt)\)。
  • 边缘：只留下前 k 个坐标的 t，其他 t 设 0；因为相应的指数因子变成 1。
  • 相互独立：当且仅当对所有向量 t，有 \(\varphi_{\boldsymbol X}(\boldsymbol t)=\prod_j\varphi_{X_j}(t_j)\)。只在 \(t_1=\cdots=t_n\) 这条线上检查乘积不够。
  • 混合矩：在相应可换序的矩存在条件下，对所需坐标求偏导，然后让所有 t=0。
\[E\left[\prod_{j=1}^nX_j^{k_j}\right]=i^{-K}\left.\frac{\partial^K\varphi(\boldsymbol t)}{\partial t_1^{k_1}\cdots\partial t_n^{k_n}}\right|_{\boldsymbol t=0},\qquad K=\sum_jk_j.\]

一个方便的充分条件是 \(E\|\boldsymbol X\|^K<\infty\)。例如 \(E[XY]=-\partial_{t_1}\partial_{t_2}\varphi(0,0)\)。

特征函数适用于所有实随机变量，但等待时间非负，可以改用始终衰减的权重；整数计数又能用幂次保存每个概率。接下来的两种变换是按取值特点选择的工具，不是额外两种随机变量。

Laplace 变换的定义：给非负量的较大取值较小权重

设 X≥0。选 s>0，把数值 x 换成权重 e⁻ˢˣ 后求平均，得到函数 LX(s)，叫X 的分布的 Laplace 变换。较大的 x 被衰减得更多。这与特征函数的单位圆箭头是不同的编码。公式也允许 s 为复数，此时 Re s 表示它的实部，要求 Re s>0 以保证衰减：

\[L_X(s)=E[e^{-sX}]=\int_{[0,\infty)}e^{-sx}\,dF_X(x),\qquad X\ge0,\ \operatorname{Re}s>0.\]

指数变成衰减权重，对寿命、等待时间等非负变量很自然。对独立非负变量的和仍可相乘，\(L_{X+Y}=L_XL_Y\)。若有密度，它就是 \(\int_0^\infty e^{-sx}f_X(x)dx\)；若有原点的概率质量，必须用 dF 的定义把它计入。

普通 Laplace 变换的 6 条运算规则

这里转换对象是一个普通函数 h，不再直接写成随机变量的分布。设 \(H(s)=\mathcal Lh(s)=\int_0^\infty e^{-sx}h(x)dx\)。一个方便的使用条件是：h 在有限区间分段光滑，且 |h(x)|≤Meᵃˣ（x 足够大），并取 Re s>a。涉及 h′ 的运算还要保证该导数在对应衰减权重下可积。

规则 直观解释
\(\mathcal L\{h'\}=sH(s)-h(0+)\) 分部积分；别漏初始值。
\(\mathcal L\{\int_0^xh(u)du\}=H(s)/s\) 积分变成除 s。
\(\mathcal L\{e^{-ax}h(x)\}=H(s+a)\) 两个衰减指数合并。
\(\mathcal L\{h(x-a)\mathbf1_{x\ge a}\}=e^{-as}H(s),\ a\ge0\) 把整个信号向后延迟 a。
\(\mathcal L(h*g)=H(s)G(s)\) 这里 G(s)=ℒg(s)。卷积 \((h*g)(x)=\int_0^xh(u)g(x-u)du\) 变乘法；独立和的密度就是这种结构。
\(h(x)=\frac1{2\pi i}\int_{c-i\infty}^{c+i\infty}e^{sx}H(s)ds\) 在上述分段光滑与指数增长条件下，取 c>a；对 x>0 的连续点恢复 h(x)，跳点则取左右极限平均。积分沿复平面的竖直线进行。

概率母函数的定义：让每个整数概率占据一个幂次

X 只取非负整数，记 pₖ=P(X=k)。选择参数 z，把取值 k 变成 zᵏ 后平均，得到 GX(z)，称概率母函数。它就是“常数项放 p₀，z 项放 p₁，z² 项放 p₂……”这份概率清单的编码：

\[G_X(z)=E[z^X]=\sum_{k=0}^\infty p_kz^k,\qquad X\in\{0,1,2,\ldots\},\quad |z|\le1.\]

它的好处是：每个概率就是对应幂次的系数。约定 \(z^0=1\)，即使 z=0。这里写 z，是为了和 Laplace 的参数 s 区分。z 可以取单位圆盘内的复数，特别包含实数区间 [−1,1]。

  1. 唯一性与取系数：\(p_k=G^{(k)}(0)/k!\)，\(|G(z)|\le G(1)=1\)。分母的 k! 不可漏。
  2. 仿射变换：若 a,b 为非负整数，\(G_{aX+b}(z)=z^bG_X(z^a)\)。
  3. 独立和：\(G_{X_1+\cdots+X_n}(z)=\prod_jG_{X_j}(z)\)；同分布时为 \([G(z)]^n\)。
  4. 求矩：\(G^{(k)}(1-)=E[X(X-1)\cdots(X-k+1)]\)，相应矩有限时成立。因此 \(EX=G'(1-)\)，\(E[X^2]=G''(1-)+G'(1-)\)。
  5. 随机项数的和：N 与整个 \(X_j\) 序列独立、各项独立同分布且非负整数时，\(S=\sum_{j=1}^NX_j\) 的母函数为 \(G_S(z)=G_N(G_X(z))\)。N=0 时和为 0。
母函数里，为什么求导能取概率和矩？

看 G(z)=p₀+p₁z+p₂z²+…：第 k 项求 k 次导数后变成 k!pₖ；更低次项导没了，更高次项还含 z。再设 z=0，只留下 k!pₖ，所以 \(p_k=G^{(k)}(0)/k!\)。

在 z=1 附近则是在读取矩。逐项求导：

\[G'(z)=\sum_{k=1}^\infty kp_kz^{k-1},\qquad G''(z)=\sum_{k=2}^\infty k(k-1)p_kz^{k-2}.\]

让 z 从左侧趋 1，幂次都趋 1，因此 G′(1−)=EX、G″(1−)=E[X(X−1)]。因为 X²=X(X−1)+X，二阶原点矩才等于 G″(1−)+G′(1−)，不是单独的二阶导数。有限矩条件保证相应结果有限。

最后一条为什么是“套函数”？先知道 N=n，得到 \([G_X(z)]^n\)；再按 N 的分布加权，恰好把 \(G_X(z)\) 塞进 \(G_N\)。例 1.7 用特征函数做同一件事。

速查表中的特征函数，也逐项说明怎么来的

Bernoulli 与二项：一次 0/1 试验按定义有 φB(t)=q+peⁱᵗ。n 次独立试验相加，把 n 个这样的函数相乘，得到 (q+peⁱᵗ)ⁿ。独立相乘的原因是 eⁱᵗ⁽ˣ⁺ʸ⁾=eⁱᵗˣeⁱᵗʸ，而独立让乘积期望拆开。

Poisson：把分布律代入定义，直接识别指数级数：

\[\varphi_K(t)=\sum_{k=0}^\infty e^{itk}e^{-\lambda}\frac{\lambda^k}{k!}=e^{-\lambda}\sum_{k=0}^\infty\frac{(\lambda e^{it})^k}{k!}=e^{\lambda(e^{it}-1)}.\]

几何：例 1.5完整把 pqᵏ⁻¹ 代入、提出首项、求等比级数，得到 peⁱᵗ/(1−qeⁱᵗ)。

均匀：按常数密度直接积分，t≠0 时：

\[\varphi_X(t)=\frac1{b-a}\int_a^b e^{itx}dx=\frac{e^{itb}-e^{ita}}{it(b-a)}.\]

t=0 时应按定义等于 E1=1，式中 0/0 形式通过取极限补上，不表示特征函数不存在。

标准正态：用 g 表示前面推导的标准正态密度，令 H(t)=∫eⁱᵗᶻg(z)dz。已有 g′(z)=−zg(z)，对 t 求导后分部积分：

\[H'(t)=i\int ze^{itz}g(z)dz=-i\int e^{itz}g'(z)dz=-tH(t).\]

边界项 eⁱᵗᶻg(z) 在 ±∞ 为 0。H(0)=1，于是一阶方程的解是 H(t)=e⁻ᵗ²⁄²。对 X=μ+σZ，再把平移缩放代入，得到：

\[\varphi_X(t)=e^{i\mu t}H(\sigma t)=e^{i\mu t-\sigma^2t^2/2}.\]

指数、Gamma、χ²：下一段给出一般 Gamma 的积分推导。代入 α=1 得到指数，代入 α=n/2、β=1/2 得到 χ²，因此不再需要把三个公式分别硬记。

Gamma 的特征函数怎样算？不靠猜，也不必用复数换元

令 X~Gamma(α,β)，取 \(\varphi(t)=\frac{\beta^\alpha}{\Gamma(\alpha)}\int_0^\infty x^{\alpha-1}e^{-(\beta-it)x}dx\)。指数衰减保证各阶矩有限。对 \(x^\alpha e^{-(\beta-it)x}\) 的导数在 0 到 ∞ 积分，边界项为 0：

\[(\beta-it)\int_0^\infty x^\alpha e^{-(\beta-it)x}dx=\alpha\int_0^\infty x^{\alpha-1}e^{-(\beta-it)x}dx.\]

左边积分恰好出现在 φ′(t) 里，因此：

\[\varphi'(t)=\frac{i\alpha}{\beta-it}\varphi(t),\qquad\varphi(0)=1.\]

解这个一阶方程，或直接求导核验，得到唯一解：

\[\boxed{\varphi(t)=(1-it/\beta)^{-\alpha}}.\]

复数幂选取从 t=0 的值 1 连续延伸的分支。α=1 是 Exp(β) 的特征函数；n 个独立 Exp(β) 相加，特征函数就是它的 n 次方，于是确实得到 Gamma(n,β)。α=n/2、β=1/2 则是例 1.6 的 χ² 特征函数。

05 / 学习指导 1.1 · 第 5 点

多维正态：多个量一起服从“钟形规律”

现在把“独立正态相加仍正态”和“联合分布要描述依赖”接起来：多个正态量一起变化时，只看每个量的钟形还不够。联合正态是一种更强的结构，使均值和协方差就能决定全部分布，第二章的 Gaussian 过程会逐次使用它。

一维正态是一座钟形山；二维正态是铺在平面上的一座山。均值决定山中心，协方差矩阵决定它往哪个方向伸长。

联合正态的定义：任意加权相加后，仍是一维正态

n 个随机量 X₁,…,Xₙ 联合正态的定义是：任取确定的实数权重 a₁,…,aₙ，线性组合 a₁X₁+…+aₙXₙ 都服从一维正态，允许方差为 0 的常数。这句话限制了它们一起变化的方式，比“每个 Xⱼ 单独正态”强得多。

把这些变量竖着排成列，记为粗体 X；小写粗体 x 是这组变量某次可能的数值向量。用 μ（粗体 mu）记录每个分量的均值，用 B 记录协方差矩阵，即第 j 行 k 列是 cov(Xⱼ,Xₖ)。记号 X~Nₙ(μ,B) 就是在给这个联合分布命名，n 是变量个数。

当 B 正定时，任何非零加权组合都有正方差，随机向量不挤在低维平面上，可以写出普通 n 维密度。先说明符号：上标 T 是转置，B⁻¹ 是逆矩阵，|B| 是行列式。这些量合起来形成下面的多元正态密度公式：

\[f(\boldsymbol x)=\frac{1}{(2\pi)^{n/2}|B|^{1/2}}\exp\!\left[-\frac12(\boldsymbol x-\boldsymbol\mu)^\top B^{-1}(\boldsymbol x-\boldsymbol\mu)\right].\]

\(|B|\) 是行列式，\(B^{-1}\) 是逆矩阵。括号里的二次型相当于“按各方向实际波动大小校准过的距离平方”。B 奇异时没有这个 n 维普通密度，但仍可定义退化正态，其概率集中在更低维的平面上。

长密度公式怎样来？从相互独立的标准钟形出发

先取 n 个独立标准正态 Zⱼ，联合密度是各自 g(zⱼ) 的乘积：

\[f_{\boldsymbol Z}(\boldsymbol z)=(2\pi)^{-n/2}\exp[-(z_1^2+\cdots+z_n^2)/2].\]

用一个确定的可逆矩阵 A 对它们缩放、混合，再平移：X=μ+AZ。A 是一张系数表，第 j 行说明 Xⱼ 用哪些 Z、各取多大权重，不是随机量。均值为 μ，协方差为 B=AAᵀ。任意正定 B 都可用这种方式得到。

变量变换反过来为 z=A⁻¹(x−μ)。小体积会被 A 放大 |det A| 倍，所以密度要除以这个倍数：

\[f_{\boldsymbol X}(\boldsymbol x)=\frac{f_{\boldsymbol Z}(A^{-1}(\boldsymbol x-\boldsymbol\mu))}{|\det A|}.\]

接下来只是两个矩阵恒等式：|B|=(det A)²，且 B⁻¹=A⁻ᵀA⁻¹。因此标准钟形里的 z₁²+…+zₙ²，替换后就是 (x−μ)ᵀB⁻¹(x−μ)；分母 |det A| 替换为 |B|¹⁄²。这就得到前面的完整密度。

公式说明什么：它仍然是“按校准后的偏差平方衰减”，只是不同方向的宽度与倾斜由协方差 B 决定。B 奇异时不能作这个可逆体积变换，故没有这种全维密度，而不是随机向量不再存在。

多元正态的特征函数公式：把同一个线性构造换成编码

粗体 t=(t₁,…,tₙ) 是特征函数的参数向量。由 X=μ+AZ，指数中的 tᵀX=tᵀμ+(Aᵀt)ᵀZ；再用独立标准正态的特征函数相乘，便得到：

\[\varphi_{\boldsymbol X}(\boldsymbol t)=\exp\!\left(i\boldsymbol t^\top\boldsymbol\mu-\frac12\boldsymbol t^\top B\boldsymbol t\right).\]

具体地，乘积中的指数平方和是 \(\|A^\top\boldsymbol t\|^2=\boldsymbol t^\top AA^\top\boldsymbol t=\boldsymbol t^\top B\boldsymbol t\)，所以密度与特征函数都使用同一个协方差结构。这个特征函数公式在 B 奇异时仍有效。

4 个核心结论

  1. 线性组合仍正态：\(Y=\boldsymbol a^\top\boldsymbol X\sim N(\boldsymbol a^\top\boldsymbol\mu,\boldsymbol a^\top B\boldsymbol a)\)。展开方差就是 \(\sum_{j,k}a_ja_k\operatorname{cov}(X_j,X_k)\)。
  2. 抽出部分分量仍联合正态：均值抽出相应坐标，B 抽出相应行与列的子矩阵。丢掉其他分量不用重新积分。
  3. 线性变换仍联合正态：若 \(\boldsymbol Y=A\boldsymbol X+\boldsymbol b\)，则 \(\boldsymbol Y\sim N_m(A\boldsymbol\mu+\boldsymbol b,ABA^\top)\)。若改用行向量写 \(Y=XC\)，对应的协方差写成 \(C^\top BC\)；这只是向量摆放方式不同。本套教程固定用列向量公式。
  4. 联合正态时，不相关等价于独立：B 的所有非对角元为 0，就能把联合特征函数拆成各边缘特征函数的乘积。

这些性质的来源也能逐条说明：第一条就是联合正态的定义，加权均值和方差来自数字特征公式；抽取部分分量，是把不需要的权重设为 0；对 Y=AX+b 的任意线性组合，又是 X 的线性组合，因此 Y 仍联合正态，均值协方差逐项展开得到。

最后一条利用特征函数：若所有非对角协方差为 0，则 \(\boldsymbol t^\top B\boldsymbol t=\sum_jB_{jj}t_j^2\)，上面的指数就拆成每个坐标各一项，特征函数分解成边缘乘积，因而独立。反向由一般的“独立推出协方差 0”即可。

算一个：\(EX=1,EY=2,DX=4,DY=9,\operatorname{cov}(X,Y)=1\)，且 (X,Y) 联合正态。则 \(2X-Y\) 的均值为 0，方差为 \(4\cdot4+9-4\cdot1=21\)，所以 \(2X-Y\sim N(0,21)\)。这里 X,Y 不独立，绝不能把交叉项丢掉。

矩阵符号看不清时，用一个二元例子展开

上面例子的均值向量与协方差矩阵是：

\[\boldsymbol\mu=\begin{pmatrix}1\\2\end{pmatrix},\quad B=\begin{pmatrix}4&1\\1&9\end{pmatrix},\quad |B|=4\cdot9-1^2=35,\quad B^{-1}=\frac1{35}\begin{pmatrix}9&-1\\-1&4\end{pmatrix}.\]

对 \(d_1=x-1,d_2=y-2\)，密度指数里的距离平方为 \((9d_1^2-2d_1d_2+4d_2^2)/35\)。它把两个坐标的尺度和相关性都考虑进去。aᵀBa 则表示先矩阵相乘再得到一个标量，不是逐元素平方。

“半正定”要求任意 a 都有 aᵀBa≥0；“正定”还要求每个非零 a 都严格大于 0。这正是任意非零线性组合的方差是否严格为正。

若 Y=X 且 X~N(0,1)，则 B 的四个元素都为 1，行列式为 0，随机向量全落在 y=x 直线上。它仍联合正态，但没有铺满平面的二维密度；特征函数和线性变换公式仍有效。这就是退化正态。

为什么“各自正态”还不够？一个反例

令 \(Z\sim N(0,1)\)，S 独立地等概率取 ±1，取 X=Z，Y=SZ。X,Y 各自标准正态，且 \(E[XY]=E[S]E[Z^2]=0\)。但 \(|X|=|Y|\)，彼此有明显依赖，不独立。它们不是联合正态：X+Y 有 1/2 的概率恰好为 0，另外一半连续波动，不是正态。

06 / 学习指导 1.1 · 第 6 点

条件期望：知道一条线索后，重新估计平均值

前面算的是没有额外信息时的平均。若先知道今天是工作日，或已知顾客总数，样本的权重就变了，估计也该跟着变。先按已知线索分组求平均，再把各组拼回去，这条线贯穿条件期望、全期望和全方差。

普通期望只给一个总平均；条件期望给一张“如果知道 Y，就该怎样预测 X”的对照表。

先按组平均，再按组的大小平均

设 Y 记录天气，X 记录销量。雨天平均卖 20，晴天平均卖 80。若雨天概率 1/4、晴天概率 3/4，则总平均是 \(20\cdot1/4+80\cdot3/4=65\)。

这里 \(E[X\mid Y=\text{雨}]\) 是一个数 20。\(E[X\mid Y]\) 则是一个随机变量：天气未揭晓时，它可能是 20，也可能是 80。竖线后的信息还随机，得到的预测也随机。

\[g(y)=E[X\mid Y=y]=\sum_xx\,p_{X\mid Y}(x\mid y)\quad\text{或}\quad\int_{-\infty}^\infty xf_{X\mid Y}(x\mid y)\,dx,\]\[E[X\mid Y]=g(Y).\]

一般写法是 \(\int x\,dF_{X\mid Y}(x\mid y)\)。有多个条件变量时只是把 y 换成向量，比如 \(E[X_i\mid X_1,\ldots,X_{i-1},X_{i+1},\ldots,X_n]\)。以下恒等式在相应可积条件下成立，随机变量间的等式理解为几乎处处相等。

全期望公式：分组没有丢失或增加权重

\[EX=E[E(X\mid Y)]=\sum_yE[X\mid Y=y]p_Y(y)\quad\text{（离散 Y）},\]\[EX=\int E[X\mid Y=y]f_Y(y)dy\quad\text{（Y 有密度）}.\]

离散情形可以把它完全展开：

\[\sum_y\left(\sum_xx\frac{p(x,y)}{p_Y(y)}\right)p_Y(y)=\sum_xx\sum_yp(x,y)=EX.\]

概率为 0 的组不影响总平均，跳过即可。E|X| 有限保证换序与相减安全；非负 X 时也可允许结果为 +∞。这条公式是第二章按人数、随机时长或随机强度取条件的基础。

四条性质：用“知道多少信息”理解

性质 为什么
\(E[E(X\mid Y)]=EX\) 先算每组平均，再按组概率平均，不会改变总平均。这是全期望公式。
独立时 \(E[X\mid Y]=EX\) 新线索不改变 X 的分布，因此也不改变均值。反过来不成立。
\(E[Xh(Y)\mid Y]=h(Y)E[X\mid Y]\) 已知 Y 后，h(Y) 就是已知数，可提出条件平均之外。不是任意随机量都能提出去。
\(E[E(X\mid Y,Z)\mid Y]=E[X\mid Y]\) 先按更细的信息预测，再退回较粗的信息，等于直接按较粗信息预测，称塔式性质。

同样，把条件扩展到多个变量，就是从 \((X_1,\ldots,X_{n-1})\) 的细信息，退回 \((X_1,\ldots,X_k)\) 的粗信息。两层信息必须有包含关系，不能对两个无关条件任意“消掉里面一层”。

另有常用的线性性 \(E[aX+bZ\mid Y]=aE[X\mid Y]+bE[Z\mid Y]\)。

一眼看懂连续条件：沿着切片重新分配密度

可以先限制在 \(y-\varepsilon<Y\le y+\varepsilon\) 的窄带里，再让 ε 趋 0。在有联合密度且满足常规条件时，就是：

\[F_{X\mid Y}(x\mid y)=\int_{-\infty}^x\frac{f(u,y)}{f_Y(y)}\,du\quad(f_Y(y)>0).\]

别把 \(E[X\mid Y]\) 理解成“直接把 X 的表达式里的字母替换一下”。一般要先找到条件分布，再按该分布求平均。例 1.9 会完整做一遍。

全方差公式：组内波动 + 组与组的均值差异

设 EX² 有限，记 g(Y)=E[X|Y]。条件方差是组内的平均平方偏差：

\[D(X\mid Y)=E[(X-g(Y))^2\mid Y].\]

把总偏差拆成 \(X-EX=(X-g(Y))+(g(Y)-EX)\)。平方后出现的交叉项期望为 0，因为给定 Y 时，g(Y)−EX 已知，且 \(E[X-g(Y)\mid Y]=0\)。所以：

\[\boxed{DX=E[D(X\mid Y)]+D(E[X\mid Y])}.\]

第一项平均“同一组内部有多散”，第二项衡量“不同组的平均值相差多大”。第二章混合 Poisson 的额外方差，正来自第二项。

用四个等概率结果核对一次

第一组的 X 为 0 或 2，第二组的 X 为 2 或 4，各组概率 1/2，组内各值也各占一半。两组均值分别 1、3，组内方差都为 1。总均值 2，总方差可以直接算成 \((4+0+0+4)/4=2\)，也可以算成组内平均方差 1，加组均值的方差 \(((1-2)^2+(3-2)^2)/2=1\)，结果相同。

为什么随机个数求和，要先知道个数？

令 N 是一小时顾客数，\(X_j\) 是第 j 位顾客消费额，各消费额独立同分布，N 与整个消费额序列独立，且 \(E|X_1|<\infty,EN<\infty\)。总消费 \(S=\sum_{j=1}^NX_j\) 看起来项数都不固定；但知道 N=n 后，它就是普通 n 项和。

\[E[S\mid N=n]=n\mu,\quad E[S\mid N]=N\mu,\quad ES=E[N\mu]=\mu EN,\qquad\mu=EX_1.\]

进一步设 \(E[X_1^2]<\infty, E[N^2]<\infty\)，记 σ²=DX₁。给定 N=n，独立性给出 D(S|N=n)=nσ²；用刚证明的全方差公式：

\[DS=E[D(S\mid N)]+D(E[S\mid N])=\sigma^2EN+\mu^2DN.\]

两项分别是“同样个数时每笔消费的波动”与“顾客个数本身的波动”。若 N 为 Poisson(λ)，得到 \(ES=\lambda\mu\)、\(DS=\lambda(\sigma^2+\mu^2)\)。例 1.7 会继续求完整特征函数。

07 / 学习指导 1.1 · 第 7 点

收敛：你说“越来越接近”，到底是哪一种？

一次观测不稳定，很多次平均是否可靠？要回答它，先得规定随机量“接近”的意思：是误差平方平均变小，还是大误差越来越少，或是一条完整记录最终稳定？下面先用定义区分这些问题，再用大数定律判断平均值。

把随机变量序列想成很多观众同时观看的连续剧：n 是集数，每位观众的一整条剧情是一条样本路径。不同收敛方式，在检查不同的东西。

四种收敛的定义：先说清每个字母是谁

X₁、X₂、……是一列随机变量，n 是序号，n→∞ 表示沿序列继续往后看。X 是我们想比较的候选极限随机变量，它可以随机，也可以是一个常数。ε（epsilon）是我们自己规定的正误差门槛。下面四种定义用了不同方式判断“接近”：

方式 精确定义 人话
依分布 \(X_n\xrightarrow d X\) \(F_n(x)\to F_X(x)\)，对 F 的每个连续点 x 只看每一集所有观众的分数直方图，形状趋于目标分布；不管某个观众的值是否接近 X。
依概率 \(X_n\xrightarrow P X\) 任意 ε>0，\(P(|X_n-X|\ge\varepsilon)\to0\) 集数很大时，随机抓一个观众，看见明显偏差的概率很小。
r 阶 / \(L^r\) 收敛 \(E|X_n-X|^r\to0\)，r>0，相关绝对矩有限 不只看偏离的人占多少，也把偏离幅度的 r 次方计入平均。
几乎处处 / 几乎必然 \(P(\lim_{n\to\infty}X_n=X)=1\) 对概率 1 的观众，各自的整条剧情最终会稳定靠近目标。

分布函数的弱收敛：在极限 F 的连续点满足 \(F_n(x)\to F(x)\)，就记 \(F_n\Rightarrow F\)。用它定义依分布收敛时，F 必须是某个随机变量的分布函数。这里必须要求 F 是合法的分布函数。比如 Xₙ=n 时，每个固定有限 x 的 Fₙ(x) 最终都为 0，但恒为 0 的函数右端不趋 1，不能当作一个实随机变量的极限分布；这些概率质量“跑到越来越远”了。

为什么只要求连续点？常数 \(X_n=1/n\to0\)，但在 x=0，\(F_n(0)=0\)，目标 \(F_X(0)=1\)，永远不相等。跳点处不要求，分布收敛依然成立。

依概率与几乎处处，差的是“检查一个时刻”还是“整条路径”

依概率收敛：固定容忍误差 ε 和小概率 δ，足够往后看，每一个单独时刻偏离至少 ε 的概率都小于 δ；但偏离者可能每次换一批，或者同一个人仍偶尔偏离。

几乎处处收敛：对概率 1 的结果 ω，沿这条路径总能找到一个起点 N(ω,ε)，以后所有时刻都不会再偏离 ε。不同路径可有不同起点，不要求全体共用同一个 N。

因此“每集偏离者越来越少”比“几乎每个观众最终不再偏离”弱。下面第三个例子直接证明这点，不需要调用另一本书的定理。

几乎处处收敛 ↘ 依概率收敛 → 依分布收敛
r 阶收敛 ↗

前两种强条件都推出依概率，后者推出依分布。r 阶到依概率直接用 Markov：\(P(|X_n-X|\ge\varepsilon)\le E|X_n-X|^r/\varepsilon^r\)。反向通常不成立；几乎处处与 r 阶之间也没有一般的互推。依分布收敛到常数 c 是特例：这时也依概率收敛到 c。

为什么箭头成立？每条用到的是哪条已讲过的规则？

r 阶 ⇒ 依概率：对非负误差的 r 次方用 Markov，不再需要猜偏离概率：

\[P(|X_n-X|\ge\varepsilon)\le E|X_n-X|^r/\varepsilon^r\to0.\]

几乎处处 ⇒ 依概率：固定 ε，令 A_N 表示“从 N 起，仍有某个时刻偏离至少 ε”。这些事件随 N 增大而缩小。路径几乎处处收敛，说明它们共同留下的事件（永远还会出现这种偏离）概率为 0。由概率连续性，P(A_N)→0，而每个 n≥N 的偏离事件都在 A_N 里，所以单次偏离概率也趋 0。

依概率 ⇒ 依分布：若 Xₙ 与 X 的差小于 ε，那么 X≤x−ε 一定保证 Xₙ≤x，而 Xₙ≤x 一定保证 X≤x+ε。只有误差大的那部分可能破坏包含关系，因此：

\[F_X(x-\varepsilon)-P(|X_n-X|\ge\varepsilon)\le F_{X_n}(x)\le F_X(x+\varepsilon)+P(|X_n-X|\ge\varepsilon).\]

先让 n→∞，两个误差概率趋 0；再让 ε↓0。在 Fₓ 连续的 x 处，左右夹到同一个 Fₓ(x)，所以分布函数收敛。这也解释了定义为何只要求在极限 CDF 的连续点检查。

三个小例子，帮助你真正区分

① 同分布却不接近：令 X 是公平的 0/1 随机变量，\(X_n=1-X\)。每个 \(X_n\) 都与 X 同分布，因此依分布收敛于 X；但 \(|X_n-X|=1\)，完全不依概率收敛于 X。

② 概率很小但幅度很大：\(U\sim U(0,1)\)，\(X_n=n\mathbf1_{\{U<1/n\}}\)。对固定 U>0，n 足够大后一直是 0，所以几乎处处趋 0，也依概率趋 0；但 \(E|X_n|=1\)，不按一阶平均误差趋 0。少数巨大值能撑住期望。

③ 单次偏离少，整条路径却不稳定：让 Xₙ 相互独立，P(Xₙ=1)=1/(n+1)，否则为 0。对任意 0<ε≤1，\(P(|X_n|\ge\varepsilon)=1/(n+1)\to0\)，所以依概率趋 0；对任意 r>0 还满足 \(E|X_n|^r=1/(n+1)\to0\)，也是 r 阶收敛。

但“从某个固定 N 起永远是 0”的概率，利用独立与缩小事件取极限可直接算：

\[P(X_n=0\text{ 对所有 }n\ge N)=\lim_{m\to\infty}\prod_{n=N}^m\frac{n}{n+1}=\lim_{m\to\infty}\frac N{m+1}=0.\]

只取 0/1 的序列若想收敛到 0，就必须从某个 N 起永远为 0。但每一个 N 对应的事件概率都是 0，可数个零概率事件的并仍是 0，所以“最终永远为 0”的概率为 0；它不几乎处处趋 0。这个例子同时说明依概率、甚至 r 阶收敛，都不能一般推出几乎处处收敛。

大数定律：平均值能不能压住随机波动？

令 \(S_n=\sum_{k=1}^nX_k\)。本章“大数定律”通常指：

\[\frac{S_n-ES_n}{n}=\frac1n\sum_{k=1}^n(X_k-EX_k)\xrightarrow P0.\]

若各项均值相同为 μ，就变成 \(S_n/n\xrightarrow P\mu\)。把“依概率”换成“几乎处处”，就是强大数定律。“平均稳定”不代表每个 \(X_n\) 本身越来越不随机。

这些定理都在回答同一个问题：样本平均能否在概率意义下接近期望平均。先看最容易验证的“独立且方差有界”，不满足时再检查弱一些的条件。它们是不同适用范围的工具，不要求每题四种都试。

4 个弱大数定律：先比对条件，再选工具

定律 条件 结论与理由
Bernoulli 独立重复试验，每次成功概率 p，n 次成功数 Nₙ \(N_n/n\xrightarrow Pp\)。频率趋近概率；方差 \(p(1-p)/n\to0\)。
Chebyshev 两两不相关，方差有限且统一有界 \(DX_k\le M\) \((S_n-ES_n)/n\xrightarrow P0\)。平均的方差≤M/n。
Khintchine（辛钦） 独立同分布，\(E|X_1|<\infty\)，\(EX_1=\mu\) \(S_n/n\xrightarrow P\mu\)。不要求有限方差，不能直接套方差证明。
Markov \(DS_n/n^2\to0\)，不强制独立 \((S_n-ES_n)/n\xrightarrow P0\)。直接套 Chebyshev。

三个方差型弱大数定律的共同计算

记 Sₙ=X₁+…+Xₙ，设 Aₙ=(Sₙ−ESₙ)/n。它的均值是 0，方差为 DSₙ/n²。对这个 Aₙ 用 Chebyshev：

\[P(|A_n|\ge\varepsilon)\le\frac{DS_n}{n^2\varepsilon^2}.\]

右边趋 0，就正好满足依概率收敛的定义。Markov 条件直接要求 DSₙ/n²→0；Chebyshev 的统一方差界保证它≤M/n；Bernoulli 成功频率则取每项方差 p(1−p)，得到 p(1−p)/n。它们看似是三个名字，其实共享这个计算。辛钦定律还允许没有有限方差，下面另有截断解释。

Markov 条件中 \(DS_n=\sum_kDX_k+2\sum_{j<k}\operatorname{cov}(X_j,X_k)\)，有依赖时必须把协方差算进去。这个条件是充分条件：它不满足，只能说此定理用不了，不能直接宣布“大数定律不成立”。例 1.12 还要利用有界性才能反证。

辛钦定律不要求有限方差，为什么仍能平均稳定？

直觉是：先把极端大值暂时截掉，剩下的有界变量就能用 Chebyshev；再证明被截掉部分的平均贡献很小。设 Xₖ 独立同分布，E|X₁| 有限，EX₁=μ。固定一个截断门槛 K：

\[U_k=X_k\mathbf1_{\{|X_k|\le K\}},\quad R_k=X_k-U_k,\quad\mu_K=EU_k.\]

Uₖ 仍独立同分布，DUₖ≤K²，所以它们的样本平均 \(\overline U_n\) 依概率趋 μK。尾部的绝对平均满足：

\[E|\overline R_n|\le E|R_1|=E[|X_1|\mathbf1_{\{|X_1|>K\}}]\longrightarrow0\quad(K\to\infty).\]

最后一步是“可积变量的尾部贡献趋 0”，也可由前面给出的支配收敛得到。Markov 因而能控制 \(\overline R_n\) 的偏离概率，且 \(|\mu-\mu_K|\le E|R_1|\)。由三角不等式：

\[|\overline X_n-\mu|\le|\overline U_n-\mu_K|+|\overline R_n|+|\mu_K-\mu|.\]

先选 K 大，让后两部分可忽略；再选 n 大，让第一部分稳定，便得到辛钦定律。这解释了为何“方差可无限，但绝对期望必须有限”仍足以保证弱大数定律。

3 个强大数定律：把路径稳定也保证下来

  1. Borel：独立同概率 p 的 Bernoulli 试验，成功频率 \(N_n/n\to p\) 几乎处处。
  2. Kolmogorov 的方差条件：\(X_n\) 相互独立、具有有限方差，若 \(\sum_{n=1}^{\infty}DX_n/n^2<\infty\)，则 \((S_n-ES_n)/n\to0\) 几乎处处。
  3. Kolmogorov 的独立同分布定理：i.i.d. 情形，样本平均几乎处处收敛到有限常数 μ，当且仅当有限期望存在且为 μ，即 \(E|X_1|<\infty,EX_1=\mu\)。

第一类适合 0/1 频率；第二类适合独立但不必同分布、方差容易算的序列；第三类直接覆盖所有有有限期望的 i.i.d. 序列。别因为它们“更强”就把各自条件忘了。

动手看 · 公平硬币的频率为什么会稳定？

实线只是一次有限模拟，帮助理解，不是定理的证明。阴影是 0.5±0.1；偏离至少 0.1 的概率上界由 Chebyshev 给出。

记忆抓手：分布看形状，概率看偏离比例，r 阶看平均误差，几乎处处看整条路径；大数定律讨论的是平均。

例 1.1 · 学习指导书页 8—9

票数最终领先，怎样才能一路都领先？

A 有 n 张选票，B 有 m 张，n>m。所有计票排列等可能。求从第一票起，每一步 A 都严格领先的概率。

入口：“每一步”是路径限制，别只算最终结果。按最后一票属于谁分情况，把长序列变成短序列。

逐步解答

记 \(p_{n,m}\) 为所求概率。如果最后一票是 A（概率 n/(n+m)），前面是 n−1 张 A、m 张 B，且前面必须始终领先；如果最后一票是 B（概率 m/(n+m)），前面是 n 张 A、m−1 张 B。于是 n>m≥1 时：

\[p_{n,m}=\frac n{n+m}p_{n-1,m}+\frac m{n+m}p_{n,m-1}.\]

边界很重要：\(p_{n,0}=1\)（n≥1），\(p_{m,m}=0\)（m≥1，最后就打平，不可能始终严格领先）。最后一票是 A 且 n=m+1 时，会用到这个“打平”边界，不能漏。

猜测 \(p_{n,m}=(n-m)/(n+m)\)，按总票数归纳。两项的分母都变成 n+m−1：

\[p_{n,m}=\frac{n(n-1-m)+m(n-m+1)}{(n+m)(n+m-1)}=\boxed{\frac{n-m}{n+m}}.\]

分子展开是 \((n-m)(n+m-1)\)。配合边界，归纳完成。这里“等可能排列”是所有 A/B 序列等可能，不是把所有可能领先路径赋予相同概率后再重新筛选。

检验：n=2,m=1 时三种排列 AAB、ABA、BAA 中只有 AAB 合格，概率 1/3；ABA 在第二票打平，不能算。最终领先远远不等于一路领先。

带走方法：能按第一步或最后一步拆分的问题，先建立递推，再找边界。
例 1.2 · 学习指导书页 9

随机拿帽子，恰好 k 人拿对

n 人的帽子混在一起，每人随机取一顶，等价于所有 n! 个排列等可能。求恰好 k 人取到自己帽子的概率。

入口：先选谁拿对，再要求剩下的人全部拿错。第二步是“错排”。

逐步解答

记 \(D_r\) 为 r 人全拿错的排列数，\(q_r=D_r/r!\)。约定 \(D_0=1\)：零个人全部拿错是空条件，算一种排法；\(D_1=0\)。

先理解容斥：总共有 r! 种，减去至少指定一人拿对的排法；两人都拿对的排法被多减了一次，要加回来；再依次减加。因此：

\[D_r=\sum_{j=0}^r(-1)^j\binom rj(r-j)!=r!\sum_{j=0}^r\frac{(-1)^j}{j!}.\]

于是挑出恰好 k 个拿对的人有 \(\binom nk\) 种，剩余 n−k 人错排：

\[P(K=k)=\frac{\binom nkD_{n-k}}{n!}=\boxed{\frac1{k!}\sum_{j=0}^{n-k}\frac{(-1)^j}{j!}},\qquad k=0,\ldots,n.\]

这比一开始追踪每个人的帽子容易。也可以沿递推路线计算错排数：

\[D_r=(r-1)(D_{r-1}+D_{r-2}),\quad q_r=\frac{r-1}{r}q_{r-1}+\frac1r q_{r-2}.\]

为什么？第一个人拿了第 j 人帽子，有 r−1 种选法。若 j 又拿第一个人的帽子，两人配成环，剩 r−2 人错排；若 j 没拿第一个人的帽子，删掉第一个人后，剩下 r−1 个人；第 j 顶帽子已经被拿走，但第 1 顶还在，把“第 1 顶”重新标成“第 j 顶”。因为第 j 人原本没拿它，其他人的正确帽子也没变，剩下就对应 r−1 人全部拿错。这个过程能反向恢复原排列，所以确实有 Dᵣ₋₁ 种。两种情况互斥且穷尽，得到递推，和容斥给出同样结果。

n 很大而 k 固定时，括号趋于 \(e^{-1}\)，故 \(P(K=k)\to e^{-1}/k!\)，也就是 Poisson(1)。

检验：n=3 时，P(K=0)=1/3，P(K=1)=1/2，P(K=2)=0，P(K=3)=1/6，总和为 1。恰好 n−1 人拿对不可能，因为最后一人也只能拿自己的。

带走方法：“恰好 k 个满足”常拆成选 k 个 + 其余全部不满足；涉及“没有任何一个”时想容斥。
例 1.3 · 学习指导书页 10—11

相邻点成对消去，最后平均剩几个孤立点？

直线上原有 n 个点。每次等概率抽取原来的一对相邻点 (i,i+1)。若任一点已被取走，则本次作废；否则取走这两个点。一直做到再无可取的相邻点，求最后孤立点数的期望。

这里的“相邻”始终指原编号相邻；删点后不会把跨过空隙的两个点接成新邻居。忽略作废的抽取，等价于每一步在仍可用的边里均匀选一条。

入口：求总数期望不必求总数分布。给每个点设 0/1 指示变量，再把“该点剩下的概率”加起来。

逐步解答

令 \(I_i=1\) 表示第 i 点最后孤立，否则为 0。则 \(R_n=\sum_iI_i\)，所以 \(ER_n=\sum_iP(I_i=1)\)，不需要各点独立。

先求一段长度为 r 的链，其端点最终孤立的概率 \(a_r\)。\(a_1=1,a_2=0\)。若第一对抽到 (j,j+1)，取走后左右分开。看右端点 n：j=n−1 时已被取走；j≤n−2 时，它在长度 n−j−1 的右侧小段里，仍是端点。因此：

\[a_n=\frac1{n-1}\sum_{r=1}^{n-2}a_r\quad(n\ge3).\]

写出 n−1 的同类式，相减得 \((n-1)a_n-(n-2)a_{n-1}=a_{n-2}\)，即：

\[a_n-a_{n-1}=-\frac{a_{n-1}-a_{n-2}}{n-1},\qquad\boxed{a_n=\sum_{j=0}^{n-1}\frac{(-1)^j}{j!}}.\]

所以 \(a_3=1/2,a_4=1/3\)，n 大时 \(a_n\to e^{-1}\)。端点比内部点更容易剩下，因为它只需躲过一侧。

再看内部第 i 点。它要同时躲过左侧与右侧，具体概率为：

\[P(I_i=1)=a_i\,a_{n-i+1}.\]

这个“乘法”值得解释：可以事先给每条原始边分配独立连续随机优先级，按从早到晚尝试配对。这与均匀随机选择剩余可用边等价。以第 i 点为界，两侧边的优先级彼此独立；第 i 点在完整链中活下来，当且仅当它在两侧单独配对过程中都活下来。因为只要一侧最先想配走它，而另一侧尚未配走，它就会被取走；若两侧都从不配走它，则它存活。乘的是这两个由独立边集决定的存活事件，不是随便假设所有孤立点独立。

\[\boxed{ER_n=\sum_{i=1}^na_i\,a_{n-i+1}}.\]

这就是精确答案，可以直接递推计算。再把 aᵢ 的有限级数代进去，按总次数 k 合并，得到一个更方便计算的等价式：

\[ER_n=\sum_{k=0}^{n-1}(n-k)\frac{(-2)^k}{k!}.\]

为什么多出 n−k？如果左右级数分别取到 r 次和 l 次，r+l=k，能容纳它们的中心点 i 有 n−k 个；而 \(\sum_{r=0}^k1/[r!(k-r)!]=2^k/k!\)，来自二项式展开。现在只剩有限和，不需要额外学习生成函数。

当 n 很大，把上限延伸到 ∞，用指数级数：

\[\sum_{k=0}^\infty\frac{(-2)^k}{k!}=e^{-2},\quad\sum_{k=0}^\infty\frac{k(-2)^k}{k!}=-2e^{-2}.\]

所以大 n 时 \(ER_n\approx(n+2)e^{-2}\)。近似遗漏的尾部绝对值不超过 \(2\sum_{j=n}^{\infty}2^j/j!\)，它趋于 0；不是只凭“每个内部点约 e⁻²”就猜出常数 2。

检验：n=3 时无论选哪对都剩 1 点；公式给 1/2+0+1/2=1。n=4 时第一对选中间会剩 2 点（概率 1/3），选两端会剩 0 点（概率 2/3），所以期望 2/3。

带走方法：总数期望 → 指示变量；遇到一维局部删除 → 按第一步切成小段。
例 1.4 · 从特征函数构造分布

给定 φ(t)=1/(1+t²)，怎样有依据地找到密度？

X 的特征函数为 \(\varphi_X(t)=1/(1+t^2)\)。求 X 的概率密度 f(x)。

入口：先分解 \(1+t^2=(1-it)(1+it)\)。这两个因子对应一个指数变量与另一个指数变量的相反数，不必凭空猜密度。

逐步解答

取 U、V 为两个独立 Exp(1) 随机变量。直接按密度积分：

\[\varphi_U(t)=\int_0^\infty e^{itx}e^{-x}dx=\frac1{1-it},\qquad\varphi_{-V}(t)=\frac1{1+it}.\]

独立和的特征函数相乘，得到：

\[\varphi_{U-V}(t)=\frac1{(1-it)(1+it)}=\frac1{1+t^2}=\varphi_X(t).\]

借唯一性，X 与 U−V 同分布。现在用卷积求这个差的密度：当 x≥0，U=V+x，所以把 V=v 从 0 积到 ∞：

\[f_{U-V}(x)=\int_0^\infty e^{-(x+v)}e^{-v}dv=\frac12e^{-x}.\]

交换 U、V 不改变联合分布，所以 U−V 关于 0 对称，x<0 时密度为 eˣ/2。合起来：

\[\boxed{f(x)=\tfrac12e^{-|x|},\quad x\in\mathbb R}.\]

这叫标准 Laplace（双边指数）分布。也能用前面给出的 Fourier 反演积分得到它；这里的“构造 + 唯一性 + 卷积”直接利用已经解释过的工具。

检验：密度非负，总面积为 \(2\int_0^\infty e^{-x}/2\,dx=1\)。EU=EV=1，所以 EX=0；独立差的方差为 DU+DV=2，与 φ″(0)=−2 相符。

带走方法：把目标特征函数分解成已知独立变量的编码，比硬猜一个密度更有方向。
例 1.5 · 学习指导书页 11

等到第一次成功：几何分布的特征函数

\(P(X=k)=pq^{k-1}\)，k=1,2,…，q=1−p，0<p≤1。求 X 的特征函数。

入口：离散变量直接按取值求和，识别等比级数。

逐步解答\[\begin{aligned}\varphi_X(t)&=\sum_{k=1}^\infty e^{itk}pq^{k-1}\\&=pe^{it}\sum_{r=0}^\infty(qe^{it})^r\\&=\boxed{\frac{pe^{it}}{1-qe^{it}}}.\end{aligned}\]

等比级数公比 \(qe^{it}\) 的模是 q<1，所以可以求和。p=1 时 X=1，公式直接退化为 \(e^{it}\)。

如果另一门课把几何分布定义为“成功之前失败了几次”，它从 0 开始，变量是这里的 X−1，特征函数就变为 \(p/(1-qe^{it})\)。少的那个 \(e^{it}\) 对应的是少计了成功那一次。

检验：t=0 时 p/(1−q)=1；求导可得 EX=1/p。先检查从 0 还是从 1 开始，是这题最容易失分的地方。

带走方法：离散分布的特征函数 → 定义求和 → 找熟悉的级数。
例 1.6 · 学习指导书页 12

χ² 分布：求编码、求矩、再求独立和

\(X\sim\chi^2(n)\)，其密度为 \(f(x)=x^{n/2-1}e^{-x/2}/[2^{n/2}\Gamma(n/2)]\)（x>0，其他处为 0）。求 φ、EX、DX；若独立的 \(X_1\sim\chi^2(n_1),X_2\sim\chi^2(n_2)\)，求和的分布。

入口：χ² 是 Gamma 的特例。积分里把两个指数合并；求和则乘特征函数。

逐步解答

设 α=n/2。它是 Gamma(α,1/2)，Gamma 特征函数的分部积分推导已给出；代入速率 1/2，或把同一计算直接写成密度积分：

\[\varphi_X(t)=\frac1{2^\alpha\Gamma(\alpha)}\int_0^\infty x^{\alpha-1}e^{-(1/2-it)x}dx=(1-2it)^{-n/2}.\]

这里复数幂取与 t=0 处值为 1 连续衔接的分支。求导时先保留因子：

\[\varphi'_X(t)=ni(1-2it)^{-n/2-1},\qquad\varphi''_X(t)=-n(n+2)(1-2it)^{-n/2-2}.\]\[EX=\frac{\varphi'(0)}i=n,\quad E[X^2]=-\varphi''(0)=n(n+2),\quad\boxed{DX=2n}.\]

独立时：

\[\varphi_{X_1+X_2}(t)=(1-2it)^{-n_1/2}(1-2it)^{-n_2/2}=(1-2it)^{-(n_1+n_2)/2}.\]

识别出 χ² 的特征函数并用唯一性得：

\[\boxed{X_1+X_2\sim\chi^2(n_1+n_2)}.\]

检验：和的均值是 n₁+n₂，方差是 2(n₁+n₂)，与独立相加吻合。分布相加结论依赖独立，不能只因两项各自是 χ² 就直接使用。

带走方法：参数能相加，通常是因为特征函数的指数能相加。
例 1.7 · 学习指导书页 12

总量 = 随机次数 × 每次随机贡献？

\(N\sim\operatorname{Poisson}(\lambda)\)，\(X_1,X_2,\ldots\) 独立同分布，具有特征函数 φ(t)，且 N 与整个序列独立。令 \(Z=\sum_{j=1}^NX_j\)，求 Z 的特征函数。N=0 时 Z=0。

入口：不要把 Z 当成 \(NX_1\)。先给定 N=k，此时是 k 个独立随机量的和。

逐步解答\[E[e^{itZ}\mid N=k]=\prod_{j=1}^kE[e^{itX_j}]=[\varphi(t)]^k.\]

k=0 时空乘积为 1，恰好对应 Z=0 的情况。再对 N 平均：

\[\begin{aligned}\varphi_Z(t)&=\sum_{k=0}^\infty[\varphi(t)]^k e^{-\lambda}\frac{\lambda^k}{k!}\\&=e^{-\lambda}\exp(\lambda\varphi(t))\\&=\boxed{\exp\{\lambda[\varphi(t)-1]\}}.\end{aligned}\]

这叫复合 Poisson 分布。你可以想成一小时订单数随机，每个订单金额也随机。“复合”指两层随机，先固定外层，内层就好算。

如果 \(EX_1=\mu,DX_1=\sigma^2\) 有限，则 \(EZ=\lambda\mu\)、\(DZ=\lambda(\sigma^2+\mu^2)\)。不是只有 λσ²，因为订单数本身也波动。

检验：若每次贡献都恰好等于 1，φ(t)=eⁱᵗ，则 Z=N，得到 Poisson 的特征函数。若每次贡献都为 0，特征函数 φZ(t) 恒为 1，对应随机变量 Z 恒为 0。

带走方法：随机项数和 → 先按项数取条件 → 指数级数求和。
例 1.8 · 学习指导书页 13

把 X 放进自己的分布函数，会发生什么？

X 的分布函数 F 连续且严格递增。求 (1) \(Y=aF(X)+b\)（a≠0）的特征函数；(2) \(Z=\ln F(X)\) 的特征函数和 \(E[Z^k]\)。

使用条件：这里明确要求 F 连续。仅“严格递增”不能排除跳跃，因此不能保证 F(X) 均匀；下面还给出完整反例。连续但不严格递增时，概率积分变换本身也成立，这一题额外给出的严格性只是方便使用普通反函数。

入口：先认出概率积分变换 \(U=F(X)\sim U(0,1)\)。之后原来的 F 形状完全不重要了。

逐步解答

连续且严格单调时，对 0<u<1：

\[P(F(X)\le u)=P(X\le F^{-1}(u))=F(F^{-1}(u))=u.\]

于是 U 均匀。第一问直接在 (0,1) 上积分：

\[\varphi_Y(t)=e^{itb}\int_0^1e^{itau}du=\boxed{e^{itb}\frac{e^{ita}-1}{ita}}\quad(t\ne0),\qquad\varphi_Y(0)=1.\]

a<0 也成立；此时 Y 在 (b+a,b) 上均匀。别误以为 a 必须为正。

第二问 Z=ln U≤0，所以 −Z=−ln U 服从参数 1 的指数分布：

\[\varphi_Z(t)=\int_0^1u^{it}du=\boxed{\frac1{1+it}}.\]

求 k 阶矩，可以求导，也可以令 v=−ln u：

\[E[Z^k]=\int_0^1(\ln u)^kdu=(-1)^k\int_0^\infty v^ke^{-v}dv=\boxed{(-1)^kk!}.\]

因此 EZ=−1，EZ²=2，DZ=1。这里 U=0 的事件概率为 0，不影响几乎处处定义的 ln U。

检验：Z 总是非正，奇数阶矩应为负，偶数阶矩应为正。如果算出 1/(1−it)，那是 −Z 的特征函数，符号弄反了。

为什么“严格单调”还不够？

取标准正态（CDF 记为 Φ）与原点质量的混合：\(F(x)=\frac12\Phi(x)+\frac12\mathbf1_{\{x\ge0\}}\)。它严格递增，但在 0 跳跃 1/2。X 有 1/2 的概率等于 0，于是 F(X) 有 1/2 的概率等于 F(0)=3/4，不可能是连续的均匀分布。

带走方法：出现 F(X)，先检查 F 是否连续；出现 −ln U，联想到指数分布。
例 1.9 · 学习指导书页 13—14

同一个联合密度，为什么两个方向的条件期望不同？

联合密度 \(f(x,y)=\frac12e^{-y}\)（y>|x|），其余处为 0。求 \(E[X\mid Y]\) 和 \(E[Y\mid X]\)。

入口：先画范围 y>|x|：一个向上的 V 形区域。固定 y 看横切片；固定 x 看竖切片。切片不同，条件分布就不同。

动手看 · 固定 Y=y 后，X 只能在 (−y,y) 内

逐步解答

第一步：求边缘。固定 x 时 y 从 |x| 到 ∞；固定 y 时 x 从 −y 到 y，且 y>0：

\[f_X(x)=\int_{|x|}^\infty\tfrac12e^{-y}dy=\tfrac12e^{-|x|},\]\[f_Y(y)=\int_{-y}^y\tfrac12e^{-y}dx=ye^{-y}\quad(y>0).\]

fY 积分为 1，也顺便核对原联合密度的归一化。

第二步：求 X|Y=y。用联合密度除以 fY：

\[f_{X\mid Y}(x\mid y)=\frac{(1/2)e^{-y}}{ye^{-y}}=\frac1{2y},\quad -y<x<y.\]

也就是以 0 为中心的均匀分布，不用硬积分也知道均值为 0：

\[\boxed{E[X\mid Y]=0}.\]

第三步：求 Y|X=x。

\[f_{Y\mid X}(y\mid x)=\frac{(1/2)e^{-y}}{(1/2)e^{-|x|}}=e^{-(y-|x|)},\quad y>|x|.\]

这是 \(|x|+\operatorname{Exp}(1)\)，所以平均为 |x|+1，最后把小写 x 换回随机变量 X：

\[\boxed{E[Y\mid X]=|X|+1}.\]

检验：由全期望 EX=0，EY=E|X|+1=2，其中 E|X|=∫₀∞xe⁻ˣdx=1；也与 Y~Gamma(2,1) 的均值 2 吻合。尽管 E[X|Y]=EX，X 与 Y 仍不独立：X 的可取范围随着 y 改变。条件均值不变只说明平均不变，不说明整个条件分布不变。

带走方法：联合密度题先看支撑范围，再求边缘、除法归一化，最后求条件平均。
例 1.10 · 学习指导书页 14

后面的观测更重要：加权平均还会趋近均值吗？

\(X_i\) 独立同分布，\(EX_i=\mu,DX_i=\sigma^2<\infty\)。令 \(Y_n=\frac{2}{n(n+1)}\sum_{i=1}^niX_i\)，证明 \(Y_n\xrightarrow P\mu\)。

入口：它不是普通等权平均，不能原样套样本平均定律。检查权重和，再算均值与方差，用 Chebyshev。

逐步解答

设 \(w_{n,i}=2i/[n(n+1)]\)。由于 \(\sum_{i=1}^ni=n(n+1)/2\)，权重和为 1：

\[EY_n=\sum_iw_{n,i}\mu=\mu.\]

独立让交叉协方差为零，方差里权重必须平方：

\[DY_n=\frac{4\sigma^2}{n^2(n+1)^2}\sum_{i=1}^ni^2=\frac{4\sigma^2}{n^2(n+1)^2}\cdot\frac{n(n+1)(2n+1)}6=\frac{2(2n+1)\sigma^2}{3n(n+1)}\to0.\]

于是对每个固定 ε>0：

\[P(|Y_n-\mu|\ge\varepsilon)\le\frac{DY_n}{\varepsilon^2}=\frac{2(2n+1)\sigma^2}{3n(n+1)\varepsilon^2}\to0.\]

这就是依概率收敛定义。实际上均方误差 \(E|Y_n-\mu|^2=DY_n\to0\)，还得到二阶收敛。

检验：最大权重是 2/(n+1)，也趋 0，没有哪一次观测长期独占平均。若权重总和不为 1，均值可能一开始就不对；若权重过度集中，方差可能压不下去。

带走方法：加权平均收敛 → 均值到目标 + 方差到 0。
例 1.11 · 学习指导书页 14—15

取值能变得很大，也能服从大数定律

\(X_n\) 相互独立，\(P(X_n=2^n)=P(X_n=-2^n)=2^{-(2n+1)}\)，\(P(X_n=0)=1-2^{-2n}\)。证明序列服从大数定律。

入口：数值幅度大不等于方差大。先让“幅度平方 × 出现概率”相乘，看是否抵消。

逐步解答

两个非零值的概率之和是 \(2\cdot2^{-(2n+1)}=2^{-2n}\)，加上取 0 的概率正好为 1。由于正负对称：

\[EX_n=0,\qquad DX_n=E[X_n^2]=2\cdot2^{2n}\cdot2^{-(2n+1)}=1.\]

虽然 n 增大时非零值越来越夸张，但出现概率以更快的速度变小，方差一直等于 1。

令 \(A_n=n^{-1}\sum_{k=1}^nX_k\)，独立给出：

\[EA_n=0,\quad DA_n=\frac1{n^2}\sum_{k=1}^nDX_k=\frac1n.\]

于是 \(P(|A_n|\ge\varepsilon)\le1/(n\varepsilon^2)\to0\)，大数定律成立。它们不是同分布，所以不该套 i.i.d. 的辛钦定律；Chebyshev 的统一方差上界正合适。

若希望更进一步，\(\sum_nDX_n/n^2=\sum_n1/n^2<\infty\)，由 Kolmogorov 方差条件还得到强大数定律。

检验：n=1 时非零两端各 1/8、零点 3/4；方差 4×(1/4)=1。要区分指数 2n 和 2n+1：两端概率相加是 2⁻²ⁿ，零点概率必须补成 1−2⁻²ⁿ，不能写成 1−2⁻ⁿ。直接检查总概率为 1 即可排除这个错误。

带走方法：不凭取值大小猜收敛，算二阶矩；非同分布也可以有大数定律。
例 1.12 · 学习指导书页 15

平均的波动始终很大，怎样证明大数定律不成立？

\(S_n=\sum_{j=1}^n\xi_j\)，存在常数 c,a>0，使 \(|S_n|<nc\)、\(DS_n>an^2\)。证明 \(\xi_n\) 序列不服从大数定律。

入口：光有“方差不趋 0”一般不够。本题多给了有界性，可以把大方差转成“偏离概率有正的下界”。

逐步解答

设 \(W_n=(S_n-ES_n)/n\)。因为 \(|S_n|<nc\)，\(|ES_n|\le E|S_n|\le nc\)，所以 \(|W_n|\le2c\)。同时：

\[E[W_n^2]=\frac{DS_n}{n^2}>a.\]

任选一个足够小的固定 ε>0，将平均平方误差按“小于 ε”和“至少 ε”拆成两块：

\[\begin{aligned}E[W_n^2]&=E[W_n^2\mathbf1_{\{|W_n|<\varepsilon\}}]+E[W_n^2\mathbf1_{\{|W_n|\ge\varepsilon\}}]\\&\le\varepsilon^2+4c^2P(|W_n|\ge\varepsilon).\end{aligned}\]

第一块每个平方都不超过 ε²；第二块每个平方都不超过 4c²。合起来得到：

\[P(|W_n|\ge\varepsilon)>\frac{a-\varepsilon^2}{4c^2}.\]

例如取 \(\varepsilon=\sqrt{a/2}\)，右侧为正常数 a/(8c²)，不随 n 缩小。因此偏离概率不可能趋 0，\(W_n\not\xrightarrow P0\)，即不服从大数定律。

也可以用反证法理解同一拆分：若偏离概率趋 0，有界性会迫使平方平均也趋 0，与方差下界矛盾。这里直接写出正下界，便能看见“不收敛”的原因。

检验：为什么不能反用 Chebyshev？因为它只说“概率≤某个数”；上界不小不意味着概率真大。本题由有界性得到的是下界，逻辑方向才对。

带走方法：证明不依概率收敛，要找到某个固定 ε，使偏离概率始终不小；不要把充分条件误当必要条件。
